<h2><span style="color:#4ea3ff;">Résumé</span></h2>
<hr class="villageois">

<p style="text-align:left; color:#f5f5f5; font-weight:bold; font-size:20px; margin-top:-10px;">
<strong>« Chaque nuit*, vous apprenez combien de joueurs morts sont maléfiques. »</strong>
</p>

<p class="botc-flavour-text dropcap">
L’<strong>ORACLE</strong> sait combien de joueurs morts sont maléfiques.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<li style="margin-bottom:14px;">Puisque l’<strong>Oracle</strong> agit après les attaques du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> chaque nuit, l’information qu’obtient l’<strong>Oracle</strong> se rapporte aux joueurs morts au moment où l’aube survient, lorsque tous les joueurs ouvrent les yeux.</li>

<li style="margin-bottom:14px;">L’<strong>Oracle</strong> détecte les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> et <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démons</a> morts, mais aussi les autres joueurs maléfiques morts, comme les <a href="../voyageurs/voyageurs.html" style="color:#9b59b6; font-weight:bold; text-decoration:none;">Voyageurs</a> maléfiques, ou les <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> ou <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> devenus maléfiques.</li>

<li style="margin-bottom:14px;">Lorsque vous comptez le nombre de joueurs morts, comptez bien les jetons <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> et <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> placés à l’envers (car cela signifie que leur alignement est l’opposé de ce qui est indiqué).</li>
</ul>

<h2><span style="color:#4ea3ff;">Comment Conter</span></h2>
<hr>

<p class="botc-flavour-text dropcap">
Instructions au Conteur
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<li style="margin-bottom:14px;">Chaque nuit, sauf la première, réveillez l’<strong>Oracle</strong>.</li>

<li style="margin-bottom:14px;">Faites signe avec vos doigts ✌🏻 (<strong>0</strong>, <strong>1</strong>, <strong>2</strong>, etc.) pour lui indiquer le nombre de joueurs maléfiques morts.</li>

<li style="margin-bottom:14px;">Ensuite, l’<strong>Oracle</strong> se rendort.</li>
</ul>

<h2><span style="color:#4ea3ff;">Exemples</span></h2>
<hr>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<li style="margin-bottom:14px;">Le premier jour, la <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a> est exécutée.<br>Cette nuit-là, le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> tue le <a href="./jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a>.<br>L’<strong>Oracle</strong> se réveille et apprend le chiffre <strong>« 0 »</strong> car tous les joueurs morts sont bons.</li>

<li style="margin-bottom:14px;">À la moitié du jeu, sept joueurs sont morts.<br>Cinq d’entre eux sont bons et deux sont maléfiques.<br>Dans la journée, un <a href="../voyageurs/voyageurs.html" style="color:#9b59b6; font-weight:bold; text-decoration:none;">Voyageur</a> maléfique est exilé.<br>Cette nuit-là, le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> tue l’un de ses <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>.<br>L’<strong>Oracle</strong> se réveille et apprend le chiffre <strong>« 4 »</strong> car quatre joueurs morts sont maléfiques.</li>
</ul>

<h2><span style="color:#4ea3ff;">Conseils &amp; Astuces</span></h2>
<hr>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<li style="margin-bottom:14px;">Tant que vous recevez un <strong>« 0 »</strong>, vous pouvez croire que tous les joueurs morts sont bons, et donc travailler avec eux et utiliser leurs informations.</li>

<li style="margin-bottom:14px;">Dès que vous recevez un <strong>« 1 »</strong> ou plus, un joueur maléfique est entré dans le royaume des morts, et vous devez désormais faire très attention aux personnes à qui vous parlez.<br>Confiez vos soupçons aux morts : ils auront intérêt à prouver qu’ils sont bons et pourront faire une grande partie du travail d’accusation pour vous.</li>

<li style="margin-bottom:14px;">La plupart des joueurs qui meurent la nuit seront des joueurs bons ; les joueurs maléfiques veulent rester en vie aussi longtemps que possible, donc le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> concentrera ses morts sur les menaces de l’équipe du bien.<br>Si vous commencez soudainement à détecter un joueur maléfique, vous devriez commencer vos soupçons par la personne exécutée le plus récemment.</li>

<li style="margin-bottom:14px;">Le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> et le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> sont deux <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démons</a> que vous pouvez détecter lorsqu’ils se déplacent dans le village.<br>Le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> provoquera des changements inattendus dans le nombre de joueurs maléfiques morts s’il touche un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> et saute vers un autre joueur, tandis que le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> éliminera probablement un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> (voire deux !) près du début de la partie afin de s’assurer que sa capacité reste active.<br>Si vous remarquez l’une de ces tendances, cherchez d’autres indices de ces <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démons</a> (par exemple, une augmentation du nombre de <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a>, ou des capacités de <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> qui continuent à s’activer alors qu’il ne reste que peu de joueurs vivants).<br>Si vous pouvez confirmer que l’un d’eux est en jeu, vous savez que ce n’est pas un <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> et vous pouvez commencer à construire une stratégie de victoire !</li>

<li style="margin-bottom:14px;">Vous pouvez tout à fait vous révéler tôt ou tard dans la partie : vous recevez des informations utiles pendant toute la partie, donc même votre toute première information peut donner beaucoup de matière à l’équipe du bien.<br>Vous pourrez peut-être aussi faire une ou deux déductions selon le moment où vous mourez : une mort précoce de l’<strong>Oracle</strong> peut indiquer un <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> inquiet, <strong>OU</strong> qu’un joueur maléfique a récemment été exécuté et que l’équipe du mal ne veut pas que vous l’appreniez.</li>
</ul>

<h2><span style="color:#4ea3ff;">Bluffer l'Oracle</span></h2>
<hr>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
Lorsque vous bluffez en prétendant être l’<strong>Oracle</strong>, gardez les points suivants à l’esprit :
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<li style="margin-bottom:14px;">Dites au groupe qu’un joueur mort (ou plus !) est maléfique, alors que tous les joueurs morts sont bons.<br>Cela rendra les morts moins dignes de confiance, ce qui poussera probablement l’équipe du bien à ignorer leurs informations.<br>Si vous faites cela lorsqu’il n’y a qu’un seul <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> en jeu, il est utile que ce <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> cesse d’utiliser sa capacité de manière visible, afin de donner l’impression qu’il est mort.<br>Par exemple, si tous les joueurs savent qu’une <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> est en jeu parce qu’un joueur est mort après avoir nommé, faire en sorte que la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> se maudisse elle-même chaque nuit retire la possibilité qu’un autre joueur meure à cause de la malédiction de la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, révélant ainsi qu’elle est encore en vie, ce qui affaiblirait votre affirmation qu’un joueur mort est maléfique.</li>

<li style="margin-bottom:14px;">Si un joueur maléfique est mort, dites au groupe que tous les joueurs morts sont bons.<br>Cela fera passer votre allié maléfique mort pour un ange, et les fausses informations qu’il diffuse auront beaucoup plus de chances d’être crues.</li>

<li style="margin-bottom:14px;">Augmentez vos nombres progressivement.<br>Il est très rare que l’équipe du bien tue un joueur maléfique chaque jour ; si vous affirmez avoir appris <strong>« 1 »</strong> la deuxième nuit, <strong>« 2 »</strong> la troisième nuit, puis <strong>« 3 »</strong> la quatrième nuit, cela paraîtra suspect.<br>Il est généralement plus crédible de dire que vous avez appris <strong>« 0 »</strong> la deuxième nuit, <strong>« 1 »</strong> la troisième nuit, <strong>« 1 »</strong> la quatrième nuit, <strong>« 1 »</strong> la cinquième nuit, <strong>« 2 »</strong> la sixième nuit, etc.</li>

<li style="margin-bottom:14px;">Si un autre <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> est en jeu, vous pouvez donner l’impression qu’un <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> ou un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> est le véritable <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>Révéler une augmentation inattendue du nombre de morts maléfiques à un moment où personne ne s’en méfie peut faire croire qu’un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> vient d’être tué par le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a>.<br>De même, si un joueur maléfique prétend être un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>, vous pouvez soudainement donner un nombre plus élevé que prévu : cela peut faire croire qu’un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> a tenté d’attaquer un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> et est mort.</li>

<li style="margin-bottom:14px;">Ces deux stratégies sont risquées sur le long terme, mais peuvent semer beaucoup de confusion à court terme.<br>Si les joueurs soupçonnent un joueur bon en particulier, et que ce joueur est exécuté, c’est le moment idéal pour augmenter votre fausse information de <strong>1</strong>.<br>Cela confirme les soupçons de l’équipe du bien : ce joueur bon était en réalité maléfique, et le travail de la journée en valait la peine.<br>Les naïfs.</li>
</ul>
