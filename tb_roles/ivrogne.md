<h3 style="color:#4ea3ff; font-weight:bold;"> Résumé</h3>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  <strong>« Vous ne savez pas que vous êtes l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>. Vous pensez être un rôle de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>, mais vous ne l’êtes pas. »</strong>
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  Le joueur <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> pense être un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> et n’a aucune idée qu’il est en réalité l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Pendant la mise en place, le jeton <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> ne va pas dans le sac.
    À la place, un jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> va dans le sac, et la personne qui le pioche est secrètement l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> pour toute la partie.
    Le Conteur le sait. Le joueur ne le sait pas.
  </li>
  <li>
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> n’a pas de capacité.
    Chaque fois que la capacité du <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> “supposé” devrait avoir un effet sur la partie, elle n’a en réalité aucun effet.
    Cependant, le Conteur fait comme si le joueur était bien ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
    Si ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> se réveille la nuit, l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> se réveille aussi.
    Si ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> doit recevoir une information, le Conteur peut donner une information fausse — et il est encouragé à le faire.
  </li>
</ul>

<hr>

<h3 style="color:#4ea3ff; font-weight:bold;"> Comment Conter</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Pendant la mise en place, avant de mettre les jetons dans le sac, retirez le jeton
    <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> et ajoutez un jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
    Ajoutez le rappel <strong>EST L’IVROGNE</strong> dans le Grimoire.
    Mettez dans le sac le jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> échangé, pas le jeton <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>.
  </li>
  <li>
    En préparant la première nuit, placez le rappel <strong>EST L’IVROGNE</strong> sur n’importe quel jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>,
    changeant secrètement le rôle de ce joueur en <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>.
    Il est maintenant un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a> et n’a pas la capacité de ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> (mais il pense que si).
  </li>
  <li>
    Pendant la partie, agissez comme si l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> était réellement ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
    Si ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> se réveille pour agir, l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> se réveille et agit.
    Si ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> devrait recevoir une information, vous pouvez lui donner une information fausse si vous le souhaitez.
  </li>
</ul>

<hr>

<h3 style="color:#4ea3ff; font-weight:bold;"> Exemples</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, qui pense être le
    <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a>,
    est attaqué par l’
    <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>.
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> meurt.
  </li>
  <li>
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, qui pense être l’
    <a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a>,
    se réveille et apprend « 0 », alors qu’il est assis à côté d’un joueur <span style="color:#d45b5b; font-weight:bold;">maléfique</span>.
    La nuit suivante, il apprend « 1 ».
  </li>
  <li>
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, qui pense être le
    <a href="./gardien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien</a>,
    est tué la nuit. Il choisit le
    <a href="./saint.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Saint</a>,
    mais apprend que ce joueur est l’
    <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a>.
  </li>
  <li>
    La
    <a href="./voyante.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Voyante</a>
    est exécutée. Cette nuit-là, l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, qui pense être le
    <a href="./croquemort.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Croque-Mort</a>,
    apprend que l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> est mort aujourd’hui.
  </li>
</ul>

<h3 style="color:#4ea3ff; font-weight:bold;"> Astuces &amp; Conseils</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Vous ne saurez jamais avec certitude que vous êtes l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> :
    vous commencez avec un jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> et vous jouez comme ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> normalement, tout en recevant de mauvaises informations.
    Découvrir que vous êtes l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> ne peut se faire que via le déroulement de la partie :
    cherchez des signes comme une information démontrablement fausse, ou une capacité qui “échoue” (par exemple, un <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a> qui meurt la nuit).
  </li>
  <li>
    Savoir qu’un <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> est en jeu est important :
    cela permet aux <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> de savoir si leurs informations doivent être scrutées davantage.
    Le signe le plus évident est un nombre d’<a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étrangers</a> différent de celui attendu
    (s’il y en a plus, il peut y avoir un <a href="./baron.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Baron</a> qui a laissé entrer un <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> en ville).
  </li>
  <li>
    Si vous suspectez un <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, essayez d’identifier quel <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> c’est le plus tôt possible.
    Il ne peut y avoir qu’un seul <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> en jeu :
    le trouver permet de traiter ses infos avec prudence, tout en rendant les autres <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> plus fiables.
  </li>
  <li>
    Distinguer l’effet de l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> de celui de l’
    <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a>
    est difficile mais crucial :
    si une seule personne semble recevoir des informations fausses, c’est peut-être l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> ;
    si plusieurs personnes reçoivent des infos parfois bonnes, parfois mauvaises, c’est probablement l’
    <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a>.
  </li>
  <li>
    Des rôles comme le
    <a href="./croquemort.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Croque-Mort</a>
    et le
    <a href="./gardien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien</a>
    verront le rôle <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> lorsqu’ils vérifient ce joueur.
    Vous ne “comptez” pas comme un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> :
    vous pensez juste l’être.
    C’est aussi vrai pour la
    <a href="./vierge.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Vierge</a> :
    un <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> ne peut pas activer sa capacité, car il n’est pas réellement <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>, mais <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a>.
  </li>
  <li>
    Si vous avez compris que vous êtes l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, essayez de “reconstruire” ce que vous savez :
    par exemple, si vous pensiez être l’<a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a> et avez eu « 0 »,
    soupçonnez qu’au moins un voisin est peut-être <span style="color:#d45b5b; font-weight:bold;">maléfique</span>.
    Ou si vous pensiez être l’<a href="./enqueteur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Enquêteur</a>,
    vous pouvez souvent supposer qu’aucun des deux joueurs vus n’est <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.
  </li>
  <li>
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> reçoit des informations peu fiables, pas “forcément fausses”.
    Dans la majorité des cas, elles seront erronées,
    mais parfois le Conteur peut vous dire la vérité si l’alternative révélerait forcément que vous êtes l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>.
  </li>
  <li>
    Gardez à l’esprit que des rôles comme le
    <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a>,
    le
    <a href="./moine.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Moine</a>
    et le
    <a href="./maire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maire</a>
    ne peuvent pas influencer la partie avec leur capacité s’ils sont en réalité l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>.
    Par exemple, un <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a> ne tuera pas un bon joueur “à la place du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>” :
    son tir échouera toujours.
  </li>
</ul>

<h3 style="color:#4ea3ff; font-weight:bold;"> Bluffer l’Ivrogne</h3>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  En bluffant l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>, gardez quelques points en tête :
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Au début, vous ne sauriez pas que vous êtes l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> :
    vous recevriez un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
    Le Conteur vous traiterait comme si vous étiez ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
  </li>
  <li>
    L’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> est le seul rôle du Bien que vous pouvez revendiquer sans qu’un autre joueur du Bien puisse vous contredire en disant “je suis ce rôle”.
  </li>
  <li>
    Bluffez un rôle qui gagne des informations de façon “passive”, comme la
    <a href="./voyante.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Voyante</a>,
    l’
    <a href="./enqueteur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Enquêteur</a>,
    l’
    <a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a>,
    la
    <a href="./lavandiere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Lavandière</a>,
    le
    <a href="./croquemort.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Croque-Mort</a>
    ou le
    <a href="./bibliothecaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Bibliothécaire</a>,
    puis donnez des informations volontairement et clairement fausses : vous aurez l’air “évidemment Ivrogne”.
  </li>
  <li>
    Bluffez un rôle dont la capacité peut “échouer”, puis réagissez avec surprise et proposez que vous soyez l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>.
    Par exemple : bluffez le <a href="./moine.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Moine</a> et dites que la personne protégée est morte quand même ;
    bluffez le <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a> et faites-vous tuer ;
    bluffez le <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a> ou nommez la <a href="./vierge.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Vierge</a> et faites semblant d’être choqué que rien ne se passe.
  </li>
  <li>
    Insinuez qu’il y a un <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> en jeu et lancez une “chasse à l’Ivrogne” :
    cela détourne l’attention de l’objectif principal (trouver le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>)
    et fait douter l’équipe du Bien de ses propres informations.
  </li>
  <li>
    Insinuez qu’un joueur particulier est <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>,
    surtout s’il a un dossier accablant contre votre équipe (par exemple, un
    <a href="./gardiendestombes.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien des Tombes</a>
    qui affirme qu’un <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a> mort était bien <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a>).
  </li>
  <li>
    Convaincre le groupe qu’un <a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> est en jeu est beaucoup plus facile si le nombre d’<a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étrangers</a> revendiqués publiquement colle avec votre histoire.
    Si un joueur <span style="color:#d45b5b; font-weight:bold;">maléfique</span> bluffe aussi <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a>, cela rend “crédible” l’idée qu’un <a href="./baron.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Baron</a> est en jeu.
  </li>
  <li>
    Si vous voulez qu’un allié <span style="color:#d45b5b; font-weight:bold;">maléfique</span> soutienne votre bluff d’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>,
    demandez-lui de revendiquer le <a href="./bibliothecaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Bibliothécaire</a>.
    Le <a href="./gardien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien</a> et le <a href="./gardiendestombes.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien des Tombes</a> fonctionnent bien aussi,
    mais l’un de vous devra mourir pour que ça marche.
  </li>
  <li>
    Si vous comptez bluffer l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a> plus tard et que vous pensez pouvoir réussir,
    donnez au début des informations “opposées” à ce que vous voulez que le Bien croie.
    Par exemple : si vous prétendez être l’<a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a> et que vous voulez faire exécuter vos voisins au final,
    dites d’abord qu’ils sont tous les deux bons.
    Si ensuite le groupe conclut que vous étiez l’<a href="./ivrogne.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Ivrogne</a>,
    il pensera qu’au moins l’un de vos voisins est <span style="color:#d45b5b; font-weight:bold;">maléfique</span> et les exécutera.
  </li>
</ul>
