##  <span style="color:#4ea3ff;">Résumé</span>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <strong>« Quand vous mourrez la nuit, un bon joueur vivant devient un fermier. »</strong>
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
Le <strong><a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a></strong> se multiplie : chaque fois qu’un <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> meurt la nuit, un autre joueur bon vivant devient à son tour <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.
</p>


<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Quand un <strong><a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a></strong> meurt <strong>dans la nuit</strong>, un autre joueur bon vivant devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.</li>
  <li>Seuls les joueurs <span style="color:#4ea3ff; font-weight:bold;">bons</span> peuvent devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> de cette façon.</li>
  <li>Si ce nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> meurt lui aussi dans la nuit, un autre joueur bon vivant devient encore <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>, et ainsi de suite.</li>
  <li>Les <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> qui meurent <strong>le jour</strong> (par exécution, exil, etc.) ne créent pas de nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.</li>
  <li>Les <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> qui sont devenus maléfiques (par exemple à cause du 
      <a href="../roles_experimentaux/mezepheles.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Mezepheles</a>)  
      peuvent toujours déclencher la création d’un nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> en mourant la nuit.  
      En revanche, les <span style="color:#4ea3ff; font-weight:bold;">Villageois</span> ou <span style="color:#4ea3ff; font-weight:bold;">Étrangers</span> devenus maléfiques ne peuvent pas devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a>.</li>
  <li>Les <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> ne se connaissent pas entre eux, mais chaque joueur qui devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> apprend qu’il est maintenant <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.</li>
  <li>Lorsqu’un joueur devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>, il perd immédiatement son ancien rôle et sa capacité.  
      Tous les effets continus de son ancienne capacité cessent aussitôt.</li>
</ul>

##  <span style="color:#4ea3ff;">Comment Conter</span>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
Si un <strong><a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a></strong> meurt cette nuit, au moment approprié de la nuit, choisissez un joueur bon vivant.  
Réveillez ce joueur, montrez-lui le jeton d’information <strong>VOUS ÊTES</strong>,  
puis le jeton de rôle <strong><a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a></strong>, puis rendormez-le.  
Remplacez son ancien jeton de rôle dans le grimoire par celui de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
Ne créez qu’un seul nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> par <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> mort dans la nuit.  
Un <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> mort le jour ne déclenche aucun changement.
</p>

##  <span style="color:#4ea3ff;">Exemples</span>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<strong>Cédric</strong> est le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
Le <span style="color:#d45b5b; font-weight:bold;">Démon</span> le tue dans la nuit.  
<strong>Nicolas</strong> est le 
<a href="../roles_experimentaux/fearmonger.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fearmonger</a>,  
et <strong>Céline</strong> est 
<a href="../roles_experimentaux/alchemist.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Alchimiste</a>.  
Comme Nicolas est maléfique, il ne peut pas devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
Céline, qui est bonne, devient le nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> cette nuit-là.
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
La deuxième nuit, le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> meurt.  
L’
<a href="../roles_experimentaux/choirboy.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Enfant de chœur</a> devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
La troisième nuit, ce nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> meurt à son tour, et l’
<a href="../roles_experimentaux/heretic.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Hérétique</a> devient alors <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
Il n’y a plus d’
<a href="../roles_experimentaux/choirboy.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Enfant de chœur</a> ni d’
<a href="../roles_experimentaux/heretic.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Hérétique</a> en jeu, mais trois <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a>, dont deux sont morts.
</p>

##  <span style="color:#4ea3ff;">Astuces et Conseils</span>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">

  <li>Si vous mourez dans la nuit, restez calme et attendez qu’un joueur vienne vous voir en disant être devenu <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      C’est un excellent moyen de créer un duo de confiance mutuelle.</li>

  <li>Le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> peut être un véritable piège pour l’équipe maléfique.  
      Si vous devenez <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> dans la nuit, allez voir en privé la personne qui était <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> avant vous  
      et annoncez-lui que vous êtes maintenant <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      Cette interaction est très difficile à imiter pour un bluffeur.</li>

  <li>Si vous souhaitez être ciblé par le <span style="color:#d45b5b; font-weight:bold;">Démon</span>,  
      révélez-vous ouvertement comme <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> et mettez-le au défi de vous tuer la nuit,  
      surtout s’il n’y a pas d’autres morts nocturnes possibles.  
      Cela peut le désorienter et le pousser à l’erreur.</li>

  <li>Vous pouvez aussi prétendre être un rôle très prioritaire, comme le 
      <a href="../roles_experimentaux/bountyhunter.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Chasseur de Primes</a>  
      ou la 
      <a href="../tb_roles/voyante.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Voyante</a>,  
      pour attirer le meurtre nocturne sur vous.  
      Une fois mort, confirmez qui est le nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> et prétendez ensuite  
      que vous avez échangé de rôle avec lui ou elle pour inciter le <span style="color:#d45b5b; font-weight:bold;">Démon</span> à le cibler à son tour.</li>

  <li>Évitez autant que possible d’être exécuté : votre capacité ne se déclenche que si vous mourrez dans la nuit.</li>

  <li>Essayez de ne pas vous dévoiler trop tôt.  
      Une grande « chaîne de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> » est bien plus puissante que quelques <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> isolés.  
      Quand plusieurs <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> sont confirmés entre eux, leur groupe devient une base solide  
      pour démarrer les accusations contre les joueurs suspects.</li>

  <li>Si le nombre de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> confirmés dépasse le nombre total de joueurs maléfiques prévu par la configuration,  
      vous pouvez généralement faire confiance à toute cette chaîne de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a>.</li>

  <li>Ne craignez pas que des rôles puissants deviennent <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermiers</a> :  
      transformer un rôle puissant en <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> est souvent bénéfique pour le Bien,  
      surtout si ce rôle avait déjà utilisé sa capacité la plus importante.</li>

  <li>Faites attention au rôle d’un joueur avant qu’il ne devienne <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> :  
      s’il était <span style="color:#4ea3ff; font-weight:bold;">Étranger</span>,  
      cela peut indiquer que la conteuse essaie de rattraper une partie difficile pour le Bien.  
      S’il était un rôle de départ ou à usage unique déjà consommé,  
      cela suggère une partie équilibrée.  
      Si un rôle très fort devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> alors qu’il y avait d’autres options,  
      cela peut signifier que le Bien est en bonne position.</li>

</ul>

##  <span style="color:#4ea3ff;">Bluffer Fermier</span>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">

  <li>Le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> est un excellent bluff de fin de partie si vous avez gardé le secret jusque-là.  
      C’est un rôle qui ne se révèle pas forcément tôt, ce qui couvre bien d’anciens bluffs fragiles.</li>

  <li>Vous pouvez dire à un ou deux joueurs en début de partie que vous êtes <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>,  
      les garder en vie longtemps, puis les accuser d’être le <span style="color:#d45b5b; font-weight:bold;">Démon</span>  
      ou un <span style="color:#d45b5b; font-weight:bold;">Sbire</span> en expliquant que,  
      s’ils étaient vraiment bons, vous seriez déjà mort la nuit depuis longtemps.</li>

  <li>Si un allié maléfique meurt dans la nuit pour une raison quelconque,  
      profitez-en pour lancer un bluff de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      Informez-le en privé que vous allez prétendre être devenu <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> à la suite de sa mort.  
      Ce duo coordonné peut être très convaincant, surtout avec un <span style="color:#d45b5b; font-weight:bold;">Démon</span> comme le 
      <a href="../sv_roles/vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a>  
      qui aime sacrifier des <span style="color:#d45b5b; font-weight:bold;">Sbires</span>.</li>

  <li>Bluffer <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> demande une certaine coordination :  
      si vous mourez dans la nuit, un autre joueur maléfique peut prétendre être le nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>,  
      confirmant ainsi votre histoire.  
      Vous ne serez pas forcément considéré comme bon,  
      mais vous renforcerez au moins l’idée que vous étiez liés.</li>

  <li>Un bluff de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> peut aussi servir à faire sortir le vrai <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> de l’ombre.  
      Si vous vous déclarez <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> publiquement, le véritable <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> pourrait être obligé  
      de vous contrer pour éviter que votre récit ne soit cru.</li>

</ul>

##  <span style="color:#4ea3ff;">Interactions à connaître</span>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">

  <li><strong>
      <a href="../roles_experimentaux/cannibal.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cannibale</a> / 
      <a href="../sv_roles/philosophe.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Philosophe</a> / 
      <a href="../roles_experimentaux/pixie.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Pixie</a>
      </strong> :  
      Si un joueur qui a gagné la capacité de <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> (par exemple le 
      <a href="../roles_experimentaux/cannibal.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cannibale</a>,  
      le 
      <a href="../sv_roles/philosophe.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Philosophe</a>  
      ou la 
      <a href="../roles_experimentaux/pixie.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Pixie</a>)  
      meurt dans la nuit, il transforme un joueur bon vivant en <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>,  
      quel que soit son véritable rôle.</li>

  <li><strong>
      <a href="../bmr_roles/femmedechambre.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Femme de chambre</a>
      </strong> :  
      Si la 
      <a href="../bmr_roles/femmedechambre.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Femme de chambre</a>  
      choisit un joueur qui commence la nuit avec un autre rôle (qui ne se réveille pas ou se réveille plus tard)  
      et qu’il devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> pendant la nuit (et se réveille pour l’apprendre),  
      ce réveil ne compte pas pour sa propre capacité.  
      Il se réveille pour être informé du changement de rôle, pas pour utiliser une capacité.  
      En revanche, s’il s’est déjà réveillé plus tôt dans la nuit pour sa capacité initiale,  
      cela comptera comme « 1 » pour la <a href="../bmr_roles/femmedechambre.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Femme de chambre</a>, même s’il est <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> ensuite.</li>

  <li><strong>
      <a href="../bmr_roles/parieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Parieur</a>
      </strong> :  
      Si un 
      <a href="../bmr_roles/parieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Parieur</a>  
      a mal parié et est déjà mort, il ne peut pas devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> plus tard dans la nuit,  
      puisqu’il est déjà mort.</li>

  <li><strong>
      <a href="../bmr_roles/commere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Commère</a>
      </strong> :  
      Si la 
      <a href="../bmr_roles/commere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Commère</a>  
      devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> avant que son commérage ne tue,  
      même un commérage correct ne tuera pas,  
      car elle a déjà perdu sa capacité de <a href="../bmr_roles/commere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Commère</a>.  
      En revanche, une <a href="../bmr_roles/commere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Commère</a> peut tuer un <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>, ce qui déclenchera bien la capacité du <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      La <a href="../bmr_roles/commere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Commère</a> qui a tué ce <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> peut même devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> elle-même.</li>

  <li><strong>
      <a href="../bmr_roles/grandmere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Grand-Mère</a>
      </strong> :  
      Si la 
      <a href="../bmr_roles/grandmere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Grand-Mère</a>  
      est la descendante et qu’elle devrait mourir tandis qu’elle devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>,  
      c’est au choix de la conteuse :  
      soit la <a href="../bmr_roles/grandmere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Grand-Mère</a> devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> et ne meurt pas (sa capacité de <a href="../bmr_roles/grandmere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Grand-Mère</a> n’étant plus en jeu),  
      soit elle meurt de sa capacité de <a href="../bmr_roles/grandmere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Grand-Mère</a> et ne devient pas <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      Le plus simple est souvent d’éviter de la transformer en <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.</li>

  <li><strong>
      <a href="../roles_experimentaux/lycanthrope.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Lycanthrope</a>
      </strong> :  
      Si le 
      <a href="../roles_experimentaux/lycanthrope.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Lycanthrope</a>  
      tue le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> puis devient lui-même <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>,  
      d’autres morts peuvent tout de même survenir cette nuit-là,  
      car il n’y a plus de capacité de <a href="../roles_experimentaux/lycanthrope.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Lycanthrope</a> en jeu pour empêcher la mort.</li>

  <li><strong>
      <a href="../sv_roles/mathematicien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mathématicien</a>
      </strong> :  
      Le 
      <a href="../sv_roles/mathematicien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mathématicien</a>  
      ne déclenche pas de +1 pour une capacité qui n’aurait pas fonctionné simplement parce qu’un joueur perd sa capacité en devenant <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      Pour le <a href="../sv_roles/mathematicien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mathématicien</a>, ce joueur est désormais un <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> dont la capacité fonctionne normalement.</li>

  <li><strong>
      <a href="../tb_roles/maire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maire</a>
      </strong> :  
      Le 
      <a href="../tb_roles/maire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maire</a>  
      peut faire rebondir l’attaque du <span style="color:#d45b5b; font-weight:bold;">Démon</span> sur le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.  
      Il peut aussi lui-même devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> après avoir fait rebondir l’attaque.</li>

  <li><strong>
      <a href="../roles_experimentaux/poppygrower.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cultivateur de pavot</a>
      </strong> :  
      Si le 
      <a href="../roles_experimentaux/poppygrower.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cultivateur de pavot</a>  
      devient <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>, les joueurs maléfiques ne se reconnaîtront plus entre eux  
      (sa capacité n’est plus en jeu).</li>

  <li><strong>
      <a href="../bmr_roles/brute.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Brute</a>
      </strong> :  
      La 
      <a href="../bmr_roles/brute.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Brute</a>  
      peut devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> si elle est bonne.  
      Le <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> ne « choisit » pas la <a href="../bmr_roles/brute.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Brute</a> avec sa capacité : c’est la conteuse qui désigne  
      le nouveau <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>. La <a href="../bmr_roles/brute.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Brute</a> ne déclenche donc pas l’ivresse d’un <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a> en devenant <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.</li>

  <li><strong>
      <a href="../tb_roles/espion.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Espion</a>
      </strong> :  
      L’
      <a href="../tb_roles/espion.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Espion</a>  
      peut être considéré comme bon pour la capacité du <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>,  
      si la conteuse le souhaite. Il peut donc, dans certains mondes, devenir <a href="./farmer.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fermier</a>.</li>

</ul>
