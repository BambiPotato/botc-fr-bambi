##  Résumé

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
« Une fois par partie, si un autre joueur a fait une nomination, vous pouvez forcer l’exécution en cours à réussir ou à échouer. »
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
Le <strong>Juge</strong> peut décider si une exécution aboutit ou non, quelle que soit la majorité obtenue.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <li>Il peut <strong>gracier</strong> (l’exécution échoue) ou <strong>condamner</strong> (l’exécution réussit).</li>
  <li>Une seule utilisation par partie.</li>
  <li>Ne peut pas agir sur une nomination qu’il a lui-même initiée.</li>
  <li>Sa décision est définitive.</li>
</ul>

---

## Comment Conter

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <li>À tout moment pendant une nomination, le Juge peut déclarer :</li>
  <ul>
    <li><strong>Exécution réussie</strong> → la personne meurt immédiatement, fin de journée.</li>
    <li><strong>Exécution échouée</strong> → la personne est graciée et considérée comme ayant reçu 0 vote.</li>
  </ul>
  <li>Après usage, placez un jeton « SANS CAPACITÉ » sur le pion du Juge.</li>
  <li>Il ne peut pas agir s’il a initié la nomination.</li>
</ul>

## Exemples

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <li>Le <a href="../bmr_roles/mercenaire.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Mercenaire</a> allait être exécuté, mais le <a href="../bmr_roles/po.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Po</a> est nommé à son tour.  
  → Tous votent, le Po est sur le point d’être exécuté.  
  → Le <span style="color:#d45b5b;">Juge maléfique</span> déclare que l’exécution échoue : le Po survit.</li>

  <li>La <a href="../bmr_roles/grand_mere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Grand-Mère</a> nomine la <a href="../bmr_roles/brute.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Brute</a>.  
  → Un seul vote est obtenu.  
  → Le <span style="color:#4ea3ff;">Juge bon</span> décide que l’exécution réussit : la <a href="../bmr_roles/goinfre.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Goinfre</a> est exécutée immédiatement.</li>

  <li>Le Juge nomine le <a href="../bmr_roles/professeur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Professeur</a>.  
  → Il ne peut pas utiliser sa capacité, car la nomination vient de lui.</li>
</ul>

##  Conseils et astuces pour les <span style="color:#4ea3ff;">Bons</span>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <li>Gardez votre pouvoir pour un moment décisif.</li>
  <li>Si peu de votes sont donnés, forcez une exécution probable d’un <span style="color:#d45b5b;">maléfique</span>.</li>
  <li>Si beaucoup de votes sont donnés, empêchez une exécution d’un <span style="color:#4ea3ff;">bon</span>.</li>
  <li>Utilisez votre pouvoir pour assurer la mort d’un <a href="../bmr_roles/po.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Po</a> ou d’un <a href="../bmr_roles/zombuul.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Zombuul</a> hésitant.</li>
  <li>Si on envisage de vous exiler, agissez avant que cela n’arrive.</li>
  <li>En cas de doute, il vaut souvent mieux sauver que condamner.</li>
  <li>Ne nominez jamais vous-même si vous voulez garder la possibilité d’agir.</li>
</ul>

---

## Conseils et astuces pour les <span style="color:#d45b5b;">Maléfiques</span>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <li>Utilisez votre capacité tôt pour influencer la dynamique du vote.</li>
  <li>Forcer une exécution est souvent plus efficace que de l’annuler.</li>
  <li>Si vous empêchez une exécution, justifiez votre geste par des arguments crédibles.</li>
  <li>Vous pouvez jouer sur la confusion en sauvant un bon joueur pour paraître loyal.</li>
  <li>Nominez un allié pour détourner les soupçons : vous ne pourrez pas agir sur votre propre nomination.</li>
  <li>En fin de partie, votre capacité peut garantir une victoire immédiate pour le Mal.</li>
</ul>

---

## Rappels utiles

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <li>Le Juge peut être exilé comme tout Voyageur.</li>
  <li>Il ne compte pas pour la condition « il ne reste que 2 joueurs en vie ».</li>
  <li>Il ne peut pas agir sur une nomination qu’il a initiée.</li>
  <li>Sa décision est définitive et irrévocable.</li>
</ul>
