##  <span style="color:#d45b5b">Résumé</span>

> « Chaque nuit*, choisissez un joueur : il meurt.  
> Les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> que vous tuez <strong>gardent leur capacité</strong> et <strong>empoisonnent un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> voisin</strong>.  
> <strong>[-1 <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a>]</strong> »

Le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> tue ses propres <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>, mais ces derniers <strong>conservent leur pouvoir</strong> tant qu’il est vivant.  
Chaque Sbire ainsi tué <strong>empoisonne un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> voisin</strong> (dans le sens horaire ou antihoraire — le Conteur choisit).  
Si le Vigormortis meurt ou perd son pouvoir, <strong>les joueurs empoisonnés redeviennent sains</strong>.  
Lors de la mise en place, il y a <strong>un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a> de moins</strong> que d’habitude.

---

##  <span style="color:#d45b5b">Comment Conter</span>

1. <strong>Préparation :</strong>  
   - Retirez <strong>1 jeton d’<a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a></strong> et ajoutez <strong>1 jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a></strong> avant de constituer le sac.  

2. <strong>Chaque nuit (sauf la première)</strong> :  
   - Réveillez le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a>.  
   - Il désigne un joueur.  
   - Si ce joueur <strong>n’est pas un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a></strong>, il <strong>meurt</strong> marquez-le avec le jeton de rappel <span style="color:#d45b5b; font-weight:bold;">MORT</span>.  
   - S’il s’agit d’un <strong><a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a></strong>, il <strong>meurt</strong>, il conserve sa capacité marquez-le avec le jeton de rappel <span style="color:#d45b5b; font-weight:bold;">MORT</span> et utilisez les jetons de rappel <span style="color:#d45b5b; font-weight:bold;">POSSÈDE UNE CAPACITÉ</span>  
     et <strong>empoisonne un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> voisin</strong>.  
   - Le <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> le plus proche du Sbire dans le sens horaire ou antihoraire est empoisonné ; indiquez-le <span style="color:#4ea3ff; font-weight:bold;">EMPOISONNÉ</span> avec le jeton de rappel.  

3. <strong>Cas particuliers :</strong>  
   - Si un Sbire mort devient un <strong>non-Sbire</strong>, il perd son pouvoir et n’empoisonne plus personne.  
   - Un Sbire mort <strong>empoisonné ou Ivre</strong> perd temporairement son effet jusqu’à redevenir sain.  
   - Si le Vigormortis meurt, <strong>tous les effets cessent</strong> immédiatement.

---

##  <span style="color:#d45b5b">Exemples</span>

- Le Vigormortis tue la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> :  
  → La malédiction de la Sorcière reste active.  
  Le joueur maudit qui nomme <strong>meurt</strong> le lendemain.  

- Le Vigormortis tue le <a href="./jumeau_malefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumeau Maléfique</a>.  
  → Le Conteur choisit un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> voisin (ex. <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a>) à <strong>empoisonner</strong>.  

- Le Vigormortis tue la <a href="./pit_hag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Pit-Hag</a>.  
  → La Pit-Hag change un joueur en <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, puis le Vigormortis la tue, conservant son effet.  

---

##  <span style="color:#d45b5b">Astuces & Stratégies</span>

- <strong>Tuez vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> vous-même !</strong>  
  En les tuant la nuit, vous leur garantissez de <strong>conserver leur pouvoir</strong> jusqu’à votre mort.  
  Une <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, un <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a> ou 
  une <a href="./pit_hag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Pit-Hag</a> active en permanence, c’est le chaos assuré.  

- <strong>Choisissez bien le moment.</strong>  
  Tant que vos Sbires vivent, ils peuvent <strong>voter</strong> pour vous aider.  
  Tuez-les seulement quand ils deviennent <strong>suspects</strong>.  

- <strong>Trompez le village :</strong>  
  Tuez des joueurs que la bonne équipe s’apprêtait à exécuter — ils croiront qu’ils étaient Sbires et ignoreront leurs infos.  

- <strong>Utilisez le poison intelligemment :</strong>  
  Le joueur empoisonné d’un Sbire mort peut <strong>désinformer durablement</strong> le Village sans s’en rendre compte.  

- <strong>Exploitez la réduction d’<a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étrangers</a> :</strong>  
  Vos Sbires peuvent <strong>bluffer</strong> en tant qu’Étrangers inexistants pour semer le doute.  

---

###  Combattre le Vigormortis

- <strong>Surveillez les morts nocturnes</strong> :  
  Des morts “inutiles” ou apparemment aléatoires peuvent révéler un <strong>Vigormortis</strong>.  

- <strong>Repèrez les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> morts encore actifs</strong> :  
  Si une <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> ou un <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a> continue d’agir après sa mort, le Vigormortis est en jeu.  

- <strong>Analysez les empoisonnements</strong> :  
  Si un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> commence soudainement à avoir de fausses infos, cela coïncide souvent avec la mort d’un Sbire.  

- <strong>En fin de partie</strong> :  
  Quand il ne reste que <strong>3 joueurs vivants</strong>, <strong>2 sont presque toujours bons</strong> dans une partie avec Vigormortis.  
  Cela vous permet de <strong>raisonner logiquement</strong> à partir de leurs infos fiables.
