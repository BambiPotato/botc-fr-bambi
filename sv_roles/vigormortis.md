<h2 style="color:#d45b5b;">Résumé</h2>

<hr class="sbire">

<p style="text-align:left; color:#f5f5f5; font-weight:bold; font-size:20px; margin:0 0 8px 0;">
Chaque nuit*, choisissez un joueur : il meurt. Les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> que vous tuez gardent leur capacité et empoisonnent 1 <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> voisin. [-1 <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>]
</p>

<p class="botc-flavour-text dropcap" style="margin-top:0;">
<strong>LE VIGORMORTIS</strong> tue ses propres <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>, qui conservent leur capacité.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">
  <li style="margin-bottom:14px;">
    Le <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> le plus proche du <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> mort, dans le sens horaire ou antihoraire, au choix du Conteur, devient empoisonné, même s’il est mort.<br>
    Si le Vigormortis meurt ou perd sa capacité d’une manière ou d’une autre, alors ces joueurs redeviennent sains.<br>
    Tuer un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> empoisonne toujours un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>, puisque les <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a>, les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> et les <a href="../voyageurs/voyageurs.html" style="color:#9b59b6; font-weight:bold; text-decoration:none;">Voyageurs</a> voisins sont ignorés.<br>
    Le Conteur choisit lequel des deux <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> est empoisonné.
  </li>

  <li style="margin-bottom:14px;">
    Tous les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> tués par le Vigormortis gardent leur capacité et empoisonnent un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>, et pas seulement le <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> qui a été tué le dernier.
  </li>

  <li style="margin-bottom:14px;">
    Si un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> mort devient un rôle qui n’est pas un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, il n’empoisonne plus de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> et n’a plus de capacité.<br>
    Si un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> mort devient ivre ou empoisonné, il perd sa capacité jusqu’à redevenir sobre et sain.
  </li>

</ul>

<h2 style="color:#d45b5b;">Comment Conter</h2>

---

<p class="botc-flavour-text dropcap" style="margin-top:0; margin-bottom:0;">
Instructions au Conteur
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Lors de la mise en place du jeu, avant de mettre les jetons de rôle dans le sac, retirez un jeton de rôle de <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> et ajoutez un jeton de rôle de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.<br>
    S’il n’y a pas de jeton de <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> à retirer, n’ajoutez pas de jeton de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
  </li>

  <li style="margin-bottom:14px;">
    Chaque nuit, sauf la première, réveillez le Vigormortis.<br>
    Il désigne n’importe quel joueur.<br>
    Le Vigormortis se rendort.<br>
    Si le joueur choisi n’est pas un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, ce joueur meurt : marquez-le d’un jeton <strong>MORT</strong>.<br>
    Si le joueur choisi est un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, ce joueur meurt : marquez-le d’un jeton <strong>MORT</strong> et associez-y un jeton <strong>A UNE CAPACITÉ</strong>.<br>
    Le <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> le plus proche du <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, dans le sens horaire ou antihoraire, est empoisonné.<br>
    Marquez-le d’un jeton <strong>EMPOISONNÉ</strong>.
  </li>

</ul>

<h2 style="color:#d45b5b;">Exemples</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Le Vigormortis tue la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>.<br>
    Le lendemain, le joueur maudit par la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> nomme quelqu’un et meurt.
  </li>

  <li style="margin-bottom:14px;">
    Le Vigormortis tue la <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a>.<br>
    La <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a> est voisine d’un <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> et d’une <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a>.<br>
    Le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> est le voisin immédiat du <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a>.<br>
    Le Conteur choisit que le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> est empoisonné.<br>
    Le lendemain, la bonne jumelle est exécutée.<br>
    Le Mal gagne.
  </li>

  <li style="margin-bottom:14px;">
    Le Vigormortis tue la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a>, qui transforme un <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> en <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>.<br>
    Le Vigormortis tue la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, qui maudit et tue un joueur.<br>
    La <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> transforme la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> morte en <a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a>, qui n’a désormais plus de capacité.<br>
    La <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> transforme le Vigormortis en <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a>.<br>
    La <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> n’a désormais plus de capacité.
  </li>

</ul>

<h2 style="color:#d45b5b;">Conseils &amp; Astuces</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Tuez vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> aussi tôt que possible.<br>
    Si vous tuez vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> la nuit, ils conservent leur capacité.<br>
    Si vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> meurent pendant la journée, ils perdent leur capacité.<br>
    Les tuer vous-même garantit qu’ils pourront continuer à utiliser leur capacité pendant le reste de la partie.<br>
    Une <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, une <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> ou un <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a> assuré d’agir chaque nuit peut représenter un avantage incroyable pour votre équipe, soit en faisant perdre leur capacité à des joueurs bons après leur mort, dans le cas de la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> et du <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a>, soit en leur faisant perdre leur capacité en les transformant en un autre rôle, dans le cas de la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a>.<br>
    Dans <a href="../sv.html" style="color:#d67bff; font-weight:bold; text-decoration:none;">Sects &amp; Violets</a>, tout ce qui permet de réduire la quantité d’informations obtenues par l’équipe du Bien avant le dernier jour est utile.
  </li>

  <li style="margin-bottom:14px;">
    Soyez patient, et écoutez ce que disent les joueurs bons.<br>
    S’ils ne soupçonnent aucun de vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>, il vaut probablement mieux les garder en vie.<br>
    Chaque jour, vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> vivants peuvent utiliser leur vote pour vous aider à éviter l’exécution, ce qui est très utile.<br>
    Tuer un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> n’apporte aucun avantage tant que vous ne pensez pas que l’équipe du Bien risque de l’exécuter.
  </li>

  <li style="margin-bottom:14px;">
    La nuit, tuez les joueurs que l’équipe du Bien comptait exécuter dès que possible.<br>
    Si vous tuez des joueurs bons suspects, il y a de fortes chances que le reste du groupe pense qu’un Vigormortis est en jeu et que le joueur mort pendant la nuit était un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.<br>
    Et s’ils croient que ce joueur bon est un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, ils n’écouteront rien de ce qu’il dit, pourront même croire l’inverse des informations qu’il a données avant sa mort, et seront peu enclins à établir une relation de confiance avec lui.<br>
    Si un <a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> ou un <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a> est en jeu, leurs informations seront perturbées, car ils baseront leur raisonnement sur la fausse supposition concernant l’identité du <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.<br>
    Cette stratégie fonctionne particulièrement bien si l’équipe du Bien a déjà des raisons de croire qu’un Vigormortis est le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> en jeu, grâce aux informations du <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>, du <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> ou de l’<a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a>.
  </li>

  <li style="margin-bottom:14px;">
    Tuer la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> ou le <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a> leur permet de continuer à utiliser leur capacité de manière indépendante après leur mort.<br>
    Tuer la <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a> signifie que l’équipe du Bien perdra si la jumelle bonne est exécutée.<br>
    Cependant, comme la plupart des joueurs n’exécuteront pas une jumelle encore seule en vie, ils auront peut-être besoin de votre aide pour être convaincus de le faire.<br>
    Tuer une <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a> la nuit supprime la possibilité que l’équipe du Bien découvre quelle jumelle est bonne et laquelle est maléfique en exécutant la jumelle maléfique — et moins l’équipe du Bien en sait, mieux c’est.
  </li>

  <li style="margin-bottom:14px;">
    Tuez la <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a> si vous pensez que l’équipe du Bien va l’exécuter.<br>
    Il vaut bien mieux qu’elle meure la nuit et que l’équipe du Bien se demande si vous n’avez pas plutôt tué la jumelle bonne.<br>
    Le bonus supplémentaire d’un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> empoisonné est également très utile.
  </li>

  <li style="margin-bottom:14px;">
    Si vous ne savez pas quel <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> tuer, choisissez celui qui est assis à côté d’un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> particulièrement gênant, afin que le Conteur puisse l’empoisonner.<br>
    Il vaut souvent mieux garder un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> dangereux en vie avec de fausses informations que le laisser mourir et paraître digne de confiance.
  </li>

  <li style="margin-bottom:14px;">
    Comme il y a un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> de moins en jeu que normalement, et que vous le savez, il peut être très facile et très efficace de bluffer en <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>.<br>
    Encore mieux — demandez à vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> de bluffer en <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a>.<br>
    Un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> qui meurt la nuit est généralement considéré comme très digne de confiance, donc s’il prétend être le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> ou la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a>, l’équipe du Bien peut croire qu’il y a beaucoup de fausses informations alors que ce n’est pas le cas.<br>
    Bluffer le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> est également un excellent choix pour les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> qui meurent la nuit.
  </li>

</ul>

<h2 style="color:#d45b5b;">Combattre le Vigormortis</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Faites attention à qui meurt la nuit.<br>
    Si les joueurs semblent mourir dans un ordre décroissant d’utilité pour l’équipe du Bien, il n’y a probablement pas de Vigormortis en jeu, et vous devriez plutôt envisager un <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a>, un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> ou un <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a>.<br>
    En revanche, si les joueurs meurent la nuit dans un ordre apparemment aléatoire, ou alors que vous pensiez que le groupe allait probablement les exécuter bientôt de toute façon… il y a probablement un Vigormortis parmi vous.<br>
    Observez qui meurt la nuit, et ce qu’ils disent.<br>
    Si vous parvenez à déterminer quels joueurs morts sont des <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>, vous pouvez inverser leurs informations, car la plupart des <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> morts mentiront.
  </li>

  <li style="margin-bottom:14px;">
    Il est souvent plus facile de comprendre qu’un Vigormortis est en jeu lors du dernier jour.<br>
    Dans <a href="../sv.html" style="color:#d67bff; font-weight:bold; text-decoration:none;">Sects &amp; Violets</a>, les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> agissent de manière très visible.<br>
    La <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> tue des joueurs lorsqu’ils nomment, et la plupart des joueurs transformés par la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> le diront au groupe.<br>
    Si vous arrivez au dernier jour et qu’un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> est toujours actif, il y a probablement un Vigormortis en jeu.<br>
    S’il ne reste que trois joueurs vivants et que vous savez que deux <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> ont agi la nuit précédente, vous faites forcément face à un Vigormortis, puisqu’il ne resterait aucun joueur bon en vie si les deux <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> étaient encore vivants.
  </li>

  <li style="margin-bottom:14px;">
    Méfiez-vous du <a href="../voyageurs/bonecollector.html" style="color:#9b59b6; font-weight:bold; text-decoration:none;">Collecteur d’os</a>.<br>
    Il peut donner l’impression qu’un Vigormortis est en jeu alors que ce n’est pas le cas.
  </li>

  <li style="margin-bottom:14px;">
    Si vous pensez savoir quels joueurs morts sont des <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>, utilisez cette information comme point de départ pour construire votre raisonnement.<br>
    Par exemple, l’<a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> peut vous indiquer où se trouve probablement le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> si vous connaissez un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> mort.<br>
    L’<a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a> peut vous dire où se trouve le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> par rapport au <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, ou confirmer que vos soupçons sont corrects.<br>
    Les informations du <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a> peuvent vous permettre de vérifier si vous avez raison ou non, et si ses informations contredisent les vôtres, ce joueur n’est peut-être finalement pas le <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a>.
  </li>

  <li style="margin-bottom:14px;">
    Si un Vigormortis est en jeu, vous pouvez raisonnablement partir du principe que lorsqu’il ne reste que trois joueurs vivants, deux d’entre eux sont bons.<br>
    C’est une information fantastique, car vous savez que toutes leurs informations ne peuvent pas être fausses.<br>
    Il n’y a ni <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> ni <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a> pour brouiller les pistes, et seules les informations de l’un des trois joueurs sont fausses.<br>
    Vous disposez alors de deux hypothèses distinctes : soit tous les joueurs disent la vérité, ce qui est possible, soit deux joueurs disent la vérité et un joueur ment, ce qui est probable.<br>
    Examinez les déclarations des trois joueurs et cherchez leurs contradictions.<br>
    Vous pourriez arriver à une situation du type : <strong>« Si A est vrai, alors B doit être vrai. Si B est vrai, alors C doit être vrai. C est faux, donc A est faux. »</strong><br>
    Cette méthode ne vous permettra peut-être pas de confirmer qui est le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>, mais en partant du principe que deux ou trois joueurs disent la vérité, vous pourrez peut-être confirmer avec certitude qu’un joueur précis de ce trio est bon.<br>
    Et confirmer que des joueurs bons sont bons est tout aussi utile que confirmer que des joueurs maléfiques sont maléfiques.
  </li>

  <li style="margin-bottom:14px;">
    S’il semble qu’un seul joueur reçoit de fausses informations, alors que la majorité des autres n’en reçoit pas, il y a probablement un Vigormortis ou un <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a> en jeu.<br>
    Dans les deux cas, commencez par exécuter les joueurs les plus proches des <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> dignes de confiance qui reçoivent de fausses informations — soit vous tuerez un <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a>, soit vous apprendrez qu’un Vigormortis est en jeu.
  </li>

  <li style="margin-bottom:14px;">
    Lorsqu’un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> commence soudainement à recevoir de fausses informations, cela vient généralement de l’empoisonnement d’un Vigormortis ou de la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a>.<br>
    Le <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> et le <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a> ont tendance à donner de fausses informations dès le début de la partie.<br>
    Si vous parvenez à identifier qu’un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> qui recevait jusque-là de vraies informations commence soudainement à en recevoir de fausses, alors vous savez également que le joueur mort la nuit où cela s’est produit est un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.<br>
    Savoir quel joueur est un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> peut être très utile, surtout lorsqu’on combine cette information avec celles de l’<a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a>, du <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a>, du <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>, de la <a href="./couturiere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Couturière</a> ou du <a href="./jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a>.
  </li>

</ul>
