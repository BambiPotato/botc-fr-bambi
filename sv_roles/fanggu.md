<h2 style="margin-top:10px;">

</h2>

---

<p style="text-align:left; color:#f5f5f5; font-weight:bold; font-size:20px; margin-top:-10px;">
« Chaque nuit*, choisissez un joueur : il meurt. <br>Le premier Marginal tué ainsi devient un Fang Gu maléfique et vous mourez à sa place. [+1 Marginal]»
</p>

<p class="botc-flavour-text dropcap">
  LE FANG GU possède les Marginaux.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">
<li>La première fois que le <strong>Fang Gu</strong> attaque et tue un Marginal, le <strong>Fang Gu</strong> meurt, et le Marginal devient un <strong>Fang Gu</strong>, et un joueur maléfique.</li>
<li>Cela ne peut arriver qu’une seule fois par partie. Si le nouveau <strong>Fang Gu</strong> attaque un Marginal, ce Marginal meurt normalement.</li>
<li>Le nouveau Fang Gu compte comme Démon et le Bien gagne s’il meurt. Il n’apprend pas quels joueurs sont des Sbires.</li>
 <li>Il y a un <strong>Marginal</strong> de plus en jeu.</li>
 <li>Si le <strong>Fang Gu</strong> attaque un <strong>Marginal</strong> mais que ce <strong>Marginal</strong> ne meurt pas, ce <strong>Marginal</strong> ne devient pas un <strong>Fang Gu</strong> maléfique et le <strong>Fang Gu</strong> ne meurt pas.</li>
</ul>

<h2 style="color:#d45b5b;">Comment Conter</h2>

---

<p class="botc-flavour-text dropcap">
Instructions au Conteur
</p> 

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Lors de la mise en place du jeu, avant de mettre les jetons de rôle dans le sac, ajoutez un jeton de rôle de <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> supplémentaire et retirez un jeton de rôle de <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a>.
  </li>

  <li style="margin-bottom:14px;">
    Chaque nuit, sauf la première, réveillez le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a>.<br>
    Il désigne n’importe quel joueur.<br>
    Le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> se rendort.
  </li>

  <li style="margin-bottom:14px;">
    Si le joueur choisi n’est pas un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>, ce joueur meurt marquez-le du jeton <strong>MORT</strong>.
  </li>

  <li style="margin-bottom:14px;">
    Si le joueur choisi est un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> et que le jeton <strong>UNE FOIS</strong> se trouve au centre du Grimoire, ce joueur meurt — marquez-le du jeton <strong>MORT</strong>.
  </li>

  <li style="margin-bottom:14px;">
    Si le joueur choisi est un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> et que le jeton <strong>UNE FOIS</strong> n’est pas au centre du Grimoire, le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> meurt — marquez-le du jeton <strong>MORT</strong>.
  </li>

  <li style="margin-bottom:14px;">
    Réveillez le <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> choisi.<br>
    Montrez-lui la tuile <strong>VOUS ÊTES</strong>, puis le jeton <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> ; puis à nouveau la tuile <strong>VOUS ÊTES</strong>, et pointez un pouce vers le bas.
  </li>

  <li style="margin-bottom:14px;">
    Changez son rôle en <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> — échangez son jeton de rôle avec un des jetons <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> supplémentaires.<br>
    Ce joueur devient maléfique.<br>
    Il se rendort.
  </li>

  <li style="margin-bottom:14px;">
    Placez le jeton <strong>UNE FOIS</strong> au centre du Grimoire.<br>
    (Contrairement aux capacités « Une fois par partie », ce jeton reste en place jusqu’à la fin de la partie.<br>
    Ne le retirez jamais, même si le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> meurt ou change de rôle.)
  </li>

</ul>

<h2 style="color:#d45b5b;">Exemples</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> attaque l’<a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a>, qui meurt.<br>
    La nuit suivante, le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> attaque la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a>, qui devient le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a>, tandis que l’ancien <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> meurt.<br>
    La <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> ne rend pas de joueur ivre, car elle n’est pas morte.<br>
    La nuit suivante, le nouveau <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> attaque le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a>, qui meurt.
  </li>

  <li style="margin-bottom:14px;">
    Le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> attaque le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> mort.<br>
    Comme le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> est mort, il ne peut pas mourir à nouveau, donc le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> ne meurt pas à sa place.<br>
    Le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> reste bon et personne ne meurt cette nuit-là.
  </li>

</ul>

<h2 style="color:#d45b5b;">Conseils &amp; Astuces</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Grâce à votre capacité à changer de corps, vous avez tout intérêt à découvrir qui sont les <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a>.<br>
    Obtenir cette information tôt est important, puisque votre principale option pour échapper aux problèmes et accroître votre puissance consiste à transmettre la capacité de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> - bien choisir le moment peut faire la différence entre une victoire triomphale du village et une victoire maléfique des plus sournoises.
  </li>

  <li style="margin-bottom:14px;">
    Lorsque les soupçons se portent sur vous et que vous pensez vous diriger bientôt vers l’échafaud, ciblez volontairement un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> afin qu’il meure à votre place, ce qui garantit que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> reste en vie (et, espérons-le, retourne se cacher parmi les joueurs bons).<br>
    Même si l’équipe du Bien soupçonne que vous avez fait cela, elle ne pourra pas empêcher que cela arrive !
  </li>

  <li style="margin-bottom:14px;">
    Sautez dans le corps d’un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> pour étendre votre empire !<br>
    Plus vous avez de joueurs maléfiques, plus vous avez de votes de votre côté.<br>
    Cela peut être risqué, puisque vous exposez potentiellement le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> lorsque vous le déplacez - des rôles comme l’<a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a> et le <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a> pourront comprendre ce genre de manigances si vous ne choisissez pas soigneusement le moment de votre saut de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>
    Malgré tout, cette puissance de vote supplémentaire est inestimable.
  </li>

  <li style="margin-bottom:14px;">
    Si vous êtes parvenu à construire un bluff solide et que l’équipe du Bien vous fait pleinement confiance, ne tuez pas de <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>.<br>
    Son bluff sera probablement moins convaincant que le vôtre, puisque vous connaissez avec certitude les rôles qui ne sont pas en jeu, donc transmettre le statut de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> à ce moment-là ne ferait que rendre l’équipe maléfique plus vulnérable.
  </li>

  <li style="margin-bottom:14px;">
    Tenez vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> informés !<br>
    Vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> (en particulier la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, le <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a> et la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a>) sont très destructeurs, et s’ils ne savent pas qui est leur <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>, la partie pourrait connaître une fin soudaine et peu satisfaisante.<br>
    Essayez de leur faire savoir à l’avance si vous comptez changer de corps/qui vous ciblez en général - ainsi, même si vous touchez par surprise un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a> qui se cachait, il ne se réveillera pas maudit, fou ou transformé en plus d’être nouvellement maléfique.
  </li>

  <li style="margin-bottom:14px;">
    Comme vous pouvez intégrer votre propre mort à vos plans à un moment donné, envisagez de profiter de certains des bluffs les plus audacieux proposés par <span style="color:#d67bff; font-weight:bold;">Sects &amp; Violets</span>.<br>
    Mourez, puis prétendez être le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> et désignez deux personnes qui ne sont pas le nouveau <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> !<br>
    Prétendez être la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> et poussez tout le monde à douter de ses informations… ou prétendez être le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> et innocentez l’un de vos joueurs maléfiques grâce à votre « choix ».<br>
    D’autres bluffs fonctionneront aussi très bien pour le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a>, mais si vous devez mourir de toute façon, pourquoi vous en priver ?
  </li>

  <li style="margin-bottom:14px;">
    Si vous devenez le nouveau <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a>… ne paniquez pas !<br>
    Votre première priorité devrait être de découvrir qui compose l’équipe maléfique - commencez par le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> récemment mort, puis cherchez les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>.<br>
    Après cela, reprenez simplement vos activités maléfiques habituelles - tuez, évitez d’être découvert, et gagnez pour votre nouvelle équipe !
  </li>

</ul>

<h2 style="color:#d45b5b;">Combattre le Fang Gu</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Apprendre qu’un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> est en jeu est la première étape pour le vaincre.<br>
    Le premier indice, et le plus important, est que le nombre de <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> qui se sont révélés est plus élevé que d’habitude.<br>
    Cela peut venir de joueurs maléfiques qui prétendent être des <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a>, ou du <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a>.
  </li>

  <li style="margin-bottom:14px;">
    Certains rôles peuvent détecter directement le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a>.<br>
    L’<a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a> détecte un nouveau joueur mort chaque fois que le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> devient un nouveau joueur.<br>
    La <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a> peut détecter lorsque le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> vote, et si ce <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> meurt la nuit, il y a probablement un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> en jeu.<br>
    Le <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>, l’<a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a> et parfois le <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> peuvent apprendre qu’un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> est en jeu, sans savoir précisément qui il est.<br>
    Si le <a href="./mathematicien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mathématicien</a> apprend constamment qu’aucun joueur ne reçoit de fausses informations, cela signifie qu’un <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> et un <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a> sont absents de la partie, et qu’un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> est bien vivant.
  </li>

  <li style="margin-bottom:14px;">
    Exécutez les <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> si vous soupçonnez qu’un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> est en jeu.<br>
    Il est rare qu’une partie entière se déroule sans que le <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> échange son rôle avec un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>, les <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> sont donc particulièrement suspects.<br>
    Il vaut probablement mieux tuer les <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> plus tard dans la partie plutôt que plus tôt, puisqu’il est alors plus probable que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> ait déjà changé de corps.
  </li>

  <li style="margin-bottom:14px;">
    Si un joueur meurt la nuit, faites attention aux personnes à qui il parle.<br>
    Les <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> morts voudront généralement parler à leurs <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> afin de leur dire qui est le nouveau <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.
  </li>

  <li style="margin-bottom:14px;">
    Si vous êtes un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>, ne révélez pas qui vous êtes avant d’être certain qu’aucun <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> n’est en jeu.<br>
    Si un <a href="./fanggu.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Fang Gu</a> est en jeu, il est probable que vous deveniez maléfique à un moment de la partie, et que vous deveniez le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>
    Si vous avez dit à l’équipe du Bien que vous êtes un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginal</a>, elle pourrait croire que vous êtes devenu maléfique, et vous tuer.
  </li>

</ul>
