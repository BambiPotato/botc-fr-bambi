<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Résumé</span>
</h2>

<p style="color:#e0c99d; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  « Chaque nuit*, choisissez un joueur : il meurt.<br>
  Le premier Étranger tué de cette façon devient un Fang Gu maléfique et vous mourez à sa place.<br>
  <strong>[+1 Étranger]</strong> »
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  Le <strong>Fang Gu</strong> est un Démon capable de <strong>transférer son pouvoir</strong> à un Étranger.<br>
  La première fois qu’il tue un Étranger, le Fang Gu meurt et l’Étranger devient un nouveau Fang Gu, rejoignant l’équipe Maléfique.<br>
  Cet effet ne peut se produire <strong>qu’une seule fois</strong> dans la partie.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Si le nouveau Fang Gu attaque un autre Étranger, celui-ci meurt normalement.</li>
  <li>Le nouveau Fang Gu devient le <strong>Démon principal</strong> : le Bien gagne s’il meurt.</li>
  <li>Il ne connaît pas les Sbires existants.</li>
  <li>Il y a <strong>un Étranger supplémentaire</strong> dans la partie.</li>
  <li>Si un Étranger ciblé ne meurt pas, rien ne change.</li>
</ul>

<hr>

<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Comment Conter</span>
</h2>

<ol style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    <strong>Lors de la mise en place :</strong>
    <ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
      <li>Ajoutez <strong>un Étranger supplémentaire</strong>.</li>
      <li>Retirez un <strong>Villageois</strong>.</li>
    </ul>
  </li>

  <li>
    <strong>Chaque nuit (sauf la première) :</strong>
    <ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
      <li>Réveillez le Fang Gu.</li>
      <li>Il désigne un joueur.</li>
      <li>Endormez-le.</li>
    </ul>
  </li>

  <li>
    <strong>Résolution :</strong>
    <ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
      <li>Si le joueur choisi n’est pas un Étranger → il meurt.</li>
      <li>
        Si le joueur choisi est un Étranger et que la transformation n’a pas encore eu lieu →
        le Fang Gu meurt, l’Étranger devient un <strong>nouveau Fang Gu maléfique</strong>.
      </li>
      <li>Si la transformation a déjà eu lieu → l’Étranger meurt normalement.</li>
    </ul>
  </li>
</ol>

<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Astuces &amp; Stratégies</span>
</h2>

<h3 style="color:#d45b5b; font-weight:bold; margin-left:20px;">En tant que Fang Gu</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    <strong>Cherchez les Étrangers.</strong><br>
    Vous devez savoir qui ils sont avant de tuer à l’aveugle, afin de bien choisir quand transmettre votre pouvoir.
  </li>

  <li>
    <strong>Évitez de mourir trop tôt.</strong><br>
    Si vous sentez que le village va vous exécuter, ciblez un Étranger pour lui transmettre le rôle et survivre indirectement.
  </li>

  <li>
    <strong>Sautez de corps au bon moment.</strong><br>
    Créer un nouveau Démon donne plus de votes maléfiques et peut semer la panique, mais c’est risqué :
    les rôles d’information comme l’
    <a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a>
    ou le
    <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>
    peuvent le remarquer.
  </li>

  <li>
    <strong>Prévenez vos Sbires.</strong><br>
    Si vous transférez le rôle, vos alliés doivent savoir qui devient le Démon, pour éviter les malentendus.
  </li>

  <li>
    <strong>Servez-vous de votre mort.</strong><br>
    Si vous mourez, profitez-en pour feindre un rôle du Bien :
    <ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
      <li>prétendez être le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> et donnez deux suspects innocents ;</li>
      <li>ou le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a> en innocentant un complice.</li>
    </ul>
  </li>

  <li>
    <strong>Si vous devenez le nouveau Fang Gu</strong>, restez calme :<br>
    votre priorité est de retrouver vos alliés maléfiques et de reprendre le contrôle de la partie.
  </li>
</ul>

<hr>

<h3 style="color:#d45b5b; font-weight:bold; margin-left:20px;">Combattre le Fang Gu</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    <strong>Trop d’Étrangers en jeu ?</strong><br>
    C’est un signe fort qu’un Fang Gu est en action.
  </li>

  <li>
    <strong>Certains rôles peuvent le détecter :</strong>
    <ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
      <li>
        L’
        <a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a>
        détecte un nouveau joueur mort la nuit.
      </li>
      <li>
        Le
        <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a>
        peut révéler quand le Démon vote.
      </li>
      <li>
        Le
        <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>
        ou le
        <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a>
        peuvent obtenir des indices sur sa présence.
      </li>
      <li>
        Le
        <a href="./mathematicien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mathématicien</a>
        peut déduire qu’il n’y a ni
        <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a>
        ni
        <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a>,
        indiquant un Fang Gu actif.
      </li>
    </ul>
  </li>

  <li>
    <strong>Méfiance envers les Étrangers.</strong><br>
    Si vous pensez qu’un Fang Gu est en jeu, les Étrangers sont des suspects prioritaires (surtout plus tard dans la partie).
  </li>

  <li>
    <strong>Observez les discussions.</strong><br>
    Un ancien Fang Gu mort cherchera probablement à contacter le nouveau Démon ou ses Sbires.
  </li>

  <li>
    <strong>Évitez d’annoncer que vous êtes un Étranger trop tôt.</strong><br>
    Si le Fang Gu est en jeu, vous risqueriez de devenir maléfique malgré vous.
  </li>
</ul>
