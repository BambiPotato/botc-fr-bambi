<h2 style="color:#4ea3ff; font-weight:bold;">Résumé</h2>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
« Si vous êtes mort aujourd’hui ou cette nuit, 
le Démon peut choisir 2 joueurs (pas un autre Démon) pour échanger leurs rôles. »
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
Quand le Barbier meurt, le Démon peut semer le chaos  
en intervertissant les rôles de deux joueurs de son choix.  
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
Leurs <strong>alignements ne changent pas</strong>,  
mais chacun découvre immédiatement <strong>le nouveau rôle</strong> qu’il obtient.  
Le Démon peut aussi <strong>ne rien faire</strong>.
</p>

<hr>

<h2 style="color:#4ea3ff; font-weight:bold;">Comment Conter</h2>

<ol style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Si le Barbier meurt, placez le jeton de rappel <strong>“COUPES DE CHEVEUX CETTE NUIT”</strong>.</li>
  <li>Cette nuit-là, <strong>réveillez le Démon</strong> :  
   - Montrez-lui le jeton <em>“ce rôle t’a choisi”</em> puis le jeton du Barbier.  
   - Il peut soit :  
     - refuser (secoue la tête),  
     - soit <strong>désigner deux joueurs</strong> (vivants ou morts).</li>
  <li>Si deux joueurs sont désignés :  
   - <strong>Échangez leurs jetons de rôle</strong>,  
   - Réveillez-les un par un pour leur montrer leur nouveau rôle,  
   - Rappelez-leur que <strong>leur alignement ne change pas</strong>.</li>
  <li>Retirez ensuite le jeton de rappel “COUPES DE CHEVEUX CETTE NUIT”.</li>
</ol>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
⚠️ Le Démon ne peut pas choisir un autre Démon,  
mais peut choisir <strong>lui-même</strong> pour participer à l’échange.
</p>

<hr>

<h2 style="color:#4ea3ff; font-weight:bold;">Exemples</h2>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Le Barbier meurt. Le Démon <strong>envisage</strong> de permuter le <a href="horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> et le <a href="jongleur.md" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a>,  
  mais renonce finalement.</li>

  <li>Le Barbier meurt. Le Démon <strong>échange</strong> le <a href="charmeur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Charmeur de Serpents</a> vivant avec le Barbier mort :  
  → Le Barbier devient vivant, et le Charmeur est maintenant mort.</li>

  <li>Le <a href="vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> se <strong>remplace</strong> lui-même avec la <a href="sorciere.md" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>.</li>

  <li>Le <a href="vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> échange sa place avec une <a href="dulcinee.md" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> morte,  
  devenant ainsi un “mauvais” Sweetheart — la partie continue grâce à un Démon bon créé la nuit précédente.</li>
</ul>

<h2 style="color:#4ea3ff; font-weight:bold;">Astuces &amp; Conseils</h2>

<h3 style="color:#4ea3ff; font-weight:bold; margin-left:20px;">Ne mourez pas trop tôt</h3>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
Votre mort offre <strong>un pouvoir monstrueux au Démon</strong>.  
Il peut bouleverser les alliances, rendre les informations fausses,  
et semer la panique dans tout le village.
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
Protégez-vous, ou <strong>bluffez un rôle que le Démon évitera</strong>,  
comme le <a href="sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> ou un rôle “épuisé” (ex. <a href="artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a>, <a href="jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a>).
</p>

<h3 style="color:#4ea3ff; font-weight:bold; margin-left:20px;">Si vous mourez malgré tout</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li><strong>Annoncez votre rôle</strong> après un court délai :  
  cela laisse aux autres joueurs le temps de révéler s’ils ont été changés.  
  (Cela renforcera votre crédibilité quand vous parlerez ensuite.)</li>

  <li>Si vous pensez que <strong>tous les Sbires sont morts</strong>,  
  mourir peut même être <strong>bénéfique</strong> :  
  le Démon ne pourra échanger que des bons joueurs (ou rien du tout).</li>
</ul>

<h3 style="color:#4ea3ff; font-weight:bold; margin-left:20px;">Pour le Démon</h3>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
Echangez des rôles comme le <a href="sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> ou un rôle qui a déjà utilisé sa capacité par exemple un <a href="artiste.md" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a>, un <a href="jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a>.  
- <strong>Échanger deux Sbires</strong> peut brouiller totalement les informations du (<a href="fleuriste.md" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a>, ou du <a href="savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a>).  
- <strong>Échanger deux bons rôles</strong> peut neutraliser un rôle gênant comme le (<a href="philosophe.md" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Philosophe</a>, ou le <a href="sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a>…).  
- <strong>Échanger un bon et un mauvais joueur</strong> est risqué,  
  car un bon joueur avec une capacité maléfique peut trahir sans le vouloir.  
- Parfois, <strong>ne rien faire</strong> est la meilleure option :  
  les joueurs douteront du Barbier ou croiront à un échange d’évil.
</p>

<hr>

<h2 style="color:#4ea3ff; font-weight:bold;">Bluffer Barbier</h2>

<h3 style="color:#4ea3ff; font-weight:bold; margin-left:20px;">Pour les joueurs maléfiques</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Les vrais Barbiers se dévoilent rarement.  
  → Imitation simple : <strong>restez discret</strong> ou prétendez un autre rôle.</li>

  <li>Vous pouvez aussi annoncer tôt que vous êtes le Barbier :  
  la plupart des joueurs préféreront vous garder en vie pour éviter un chaos prématuré.</li>

  <li>Si vous mourez, aucun bon joueur ne dira avoir été échangé :  
  vous devrez donc <strong>convaincre</strong> que le Démon n’a rien fait  
  ou qu’il a échangé <strong>deux Sbires</strong>.</li>

  <li><strong>Combinaison maléfique</strong> :  
  si vous êtes trois par exmeple un Démon et deux Sbires),  
  faites mourir votre “Barbier” fictif, puis vos complices  
  annoncent s’être “échangés”.  
  → Vous gagnez la confiance totale du village.</li>
</ul>
