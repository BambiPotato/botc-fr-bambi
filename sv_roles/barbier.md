<h2 style="color:#4ea3ff; font-weight:bold;">Résumé</h2>

<hr class="villageois">

<p style="text-align:left; color:#f5f5f5; font-weight:bold; font-size:20px; margin-top:-10px;">
<strong>« Si vous êtes mort dans la journée ou cette nuit, le Démon peut choisir 2 joueurs (mais pas un autre Démon) qui échangent alors leur rôle.»</strong>
</p>

<p class="botc-flavour-text dropcap" style="margin-top:0;">
<strong>LE BARBIER</strong> permet au <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> d’échanger deux rôles.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Les alignements des joueurs restent les mêmes lorsqu’ils changent de rôle.<br>
    Chaque joueur apprend le rôle qu’il devient.
  </li>

  <li style="margin-bottom:14px;">
    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> peut choisir de ne pas échanger deux rôles.
  </li>

  <li style="margin-bottom:14px;">
    Si un joueur devient un nouveau rôle, il gagne sa capacité, même s’il s’agit d’une capacité <strong>« Lors de votre première nuit, vous apprenez »</strong> ou <strong>« une fois par partie »</strong> déjà utilisée.
  </li>

  <li style="margin-bottom:14px;">
    S’il y a plus d’un <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> en vie, le Conteur choisit quel <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> procède à l’échange.
  </li>

  <li style="margin-bottom:14px;">
    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> peut échanger son propre rôle.
  </li>

  <li style="margin-bottom:14px;">
    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> ne peut pas choisir un autre <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> pour lui faire échanger son rôle.
  </li>

  <li style="margin-bottom:14px;">
    Si un joueur meurt, puis devient le Barbier, le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> ne peut pas procéder à l’échange cette nuit-là.
  </li>

</ul>

<h2 style="color:#4ea3ff;">Comment Conter</h2>

---

<p class="botc-flavour-text dropcap">
Instructions au Conteur
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Si le Barbier meurt, marquez-le du jeton <strong>CETTE NUIT, ON RASE GRATIS</strong>.
  </li>

  <li style="margin-bottom:14px;">
    Lors de cette nuit, réveillez le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>
    Montrez-lui la tuile <strong>CE RÔLE VOUS A CHOISI</strong>, puis le jeton Barbier.<br>
    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> fait non de la tête ou désigne deux joueurs.<br>
    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> se rendort.<br>
    Retirez le jeton <strong>CETTE NUIT, ON RASE GRATIS</strong>.
  </li>

  <li style="margin-bottom:14px;">
    Si le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> désigne deux joueurs, échangez les jetons de rôle de ces joueurs, puis réveillez-les un par un et montrez-leur la tuile <strong>VOUS ÊTES</strong>, puis leur nouveau jeton de rôle.<br>
    Ces joueurs se rendorment.<br>
    Si l’alignement d’un joueur ne correspond pas à la couleur de son jeton de rôle, faites-le pivoter pour l’afficher à l’envers.
  </li>

</ul>

<div class="botc-note">
Si un joueur bon devient un Sbire ou un Démon, ou si un joueur maléfique devient un Villageois ou un Marginal, vous pouvez lui rappeler que son alignement n’a pas changé.
</div>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">

    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> envisage d’échanger l’<a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> et le <a href="./jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a>, mais se ravise et ne fait rien.
  </li>

  <li style="margin-bottom:14px;">
    Le Barbier meurt.<br>
    Le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> échange l’<a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a> en vie contre le Barbier mort.<br>
    Désormais, il y a un Barbier en vie et un <a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a> mort.
  </li>

  <li style="margin-bottom:14px;">
    Le Barbier meurt.<br>
    Le <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> s’échange avec une <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> en vie.
  </li>

  <li style="margin-bottom:14px;">
    Le Barbier meurt.<br>
    Le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> s’échange avec une <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> morte.<br>
    L’ancien <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> est désormais une <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> maléfique.<br>
    Comme la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a> a créé un <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> bon lors de la nuit précédente, la partie continue.
  </li>

</ul>

<h2 style="color:#4ea3ff;">Conseils &amp; Astuces</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">
  <li style="margin-bottom:14px;">
    Ne mourez pas !<br>
    Votre mort donnera immédiatement un énorme avantage à l’équipe maléfique : elle disposera de nombreuses possibilités grâce à votre capacité d’échange de rôles, et l’utilisera sans aucun doute pour perturber au maximum l’équipe du Bien.
  </li>

  <li style="margin-bottom:14px;">
    Bluffez un rôle peu intéressant pour le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>
    Afin d’augmenter vos chances de survie, prétendez être un rôle que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> n’a aucune envie de tuer, comme le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a>, qu’il préfère éviter à tout prix, ou un rôle comme l’<a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a> ou le <a href="./jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a> ayant déjà utilisé sa capacité.<br>
    Si le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> vous considère comme une cible de faible priorité, il s’attaquera à d’autres joueurs, ce qui augmentera vos chances de rester en vie.<br>
    (Il peut toutefois être utile de révéler secrètement votre véritable identité à un ou deux joueurs afin qu’ils sachent que les <strong>« informations »</strong> que vous donnez sont fausses.)
  </li>

  <li style="margin-bottom:14px;">
    Si vous mourez, révélez-vous… mais pas forcément immédiatement.<br>
    Il est important que les joueurs sachent qu’un échange du Barbier a eu lieu, mais si vous attendez quelques minutes, les joueurs bons ayant changé de rôle viendront souvent d’eux-mêmes l’annoncer.<br>
    En vous révélant après eux, vous paraîtrez bien plus crédible.
  </li>

  <li style="margin-bottom:14px;">
    Mourir volontairement peut être une bonne stratégie dans certaines parties.<br>
    Par exemple, si vous pensez connaître tous les joueurs maléfiques, <strong>OU</strong> si vous êtes certain que la plupart d’entre eux sont déjà morts.<br>
    Dans ces situations, l’échange le plus difficile à détecter, entre deux joueurs maléfiques, devient impossible, ce qui pousse davantage le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> à échanger deux joueurs bons, vous confirmant ainsi, ou à ne procéder à aucun échange afin de limiter l’impact de votre capacité.
  </li>

  <li style="margin-bottom:14px;">
    Si vous êtes un joueur bon et que votre rôle change la nuit où le Barbier meurt, il est généralement préférable de l’annoncer au village dès le lendemain.<br>
    Vous confirmez ainsi la présence du Barbier et pourrez retrouver plus facilement le joueur avec lequel vous avez été échangé.<br>
    Sauf si vous avez été échangé avec un joueur maléfique, l’autre joueur aura probablement lui aussi intérêt à se révéler, ce qui vous permettra de lui faire confiance !
  </li>

  <li style="margin-bottom:14px;">
    Au secours, je suis le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> et le Barbier vient de mourir !<br>
    La capacité du Barbier est extrêmement polyvalente et puissante, mais elle peut être délicate à utiliser, surtout si vous le tuez sans l’avoir prévu.<br>
    Voici quelques possibilités :
  </li>

  <li style="margin-bottom:14px;">
    Échangez deux joueurs maléfiques.<br>
    Dans la plupart des cas, cela sert à déplacer le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> vers un autre joueur maléfique, ce qui invalide les informations de nombreux rôles bons, comme la <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a>, le <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> ou même le <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>.<br>
    Un changement de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> bien synchronisé peut complètement détourner les soupçons de l’équipe du Bien.
  </li>

  <li style="margin-bottom:14px;">
    Échangez deux joueurs bons !<br>
    N’oubliez pas que vous pouvez échanger un joueur vivant avec un joueur mort.<br>
    Vous pouvez ainsi neutraliser un <a href="./philosophe.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Philosophe</a> ou un <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> gênant, entre bien d’autres rôles problématiques… simplement en l’échangeant avec le Barbier fraîchement décédé.<br>
    Vous pouvez également échanger une <a href="./mutant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Bête de foire</a> connue afin de placer un joueur dans une situation délicate où il lui sera difficile d’admettre publiquement son changement de rôle.<br>
    Enfin, vous pouvez tout simplement échanger deux joueurs au hasard afin de semer la confusion !<br>
    Attention toutefois : les joueurs bons sauront qu’ils ont été échangés, connaîtront désormais le rôle de l’autre et pourront se faire confiance.<br>
    Assurez-vous que neutraliser ce <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> gênant vaut bien cette nouvelle information.
  </li>

  <li style="margin-bottom:14px;">
    Échangez un joueur bon et un joueur maléfique.<br>
    Ce n’est généralement pas une bonne idée, car un joueur bon doté d’une capacité maléfique peut causer énormément de dégâts à votre équipe.<br>
    Une bonne <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> ou un bon <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a>, par exemple, peuvent être très dangereux.<br>
    Cependant, ils peuvent devenir si dangereux pour les deux camps que l’équipe du Bien décidera d’exécuter ce joueur bon devenu un rôle maléfique après qu’il l’aura annoncé.<br>
    Cela fonctionne aussi dans l’autre sens : si un joueur maléfique obtient un rôle bon puissant, cela peut être dévastateur.<br>
    Par exemple, un joueur maléfique devenant une <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a>, un <a href="./philosophe.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Philosophe</a> ou un <a href="./charmeurdeserpent.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Charmeur de serpents</a> peut être extrêmement redoutable.
  </li>

  <li style="margin-bottom:14px;">
    Parfois, la meilleure décision est de ne rien faire lorsque le Barbier meurt.<br>
    Si aucun échange de rôles bons ne vous semble intéressant et que la répartition actuelle des rôles maléfiques vous convient, ne faites aucun échange.<br>
    Comme cela n’a aucun effet visible sur la partie, votre position reste solide, tout en laissant croire soit que le Barbier ment, soit que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> et un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> ont échangé leurs rôles.<br>
    Dans les deux cas, cela crée de fausses pistes qui détourneront l’attention de l’équipe du Bien.
  </li>

</ul>

<h2 style="color:#4ea3ff;">Bluffer le Barbier</h2>

---

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
<strong>Lorsque vous bluffez le Barbier,</strong> il y a quelques éléments à garder en tête :
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">
  <li style="margin-bottom:14px;">
    Les véritables Barbiers ne révèlent généralement pas tout de suite leur rôle.<br>
    Restez discret sur votre identité, ou bluffez un autre rôle tant que vous êtes en vie.
  </li>

  <li style="margin-bottom:14px;">
    Vous pouvez également vous révéler très tôt en disant que vous êtes le Barbier.<br>
    Les joueurs voudront malgré tout probablement vous garder en vie.<br>
    Dans un cas comme dans l’autre, cela reste une stratégie viable.
  </li>

  <li style="margin-bottom:14px;">
    Si vous mourez, aucun joueur bon ne verra réellement son rôle échangé.<br>
    Par conséquent, aucun joueur bon ne viendra annoncer au groupe que son rôle a changé.<br>
    Vous devrez donc convaincre le village que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> n’a effectué aucun échange… ou qu’il a échangé deux joueurs maléfiques.
  </li>

  <li style="margin-bottom:14px;">
    Double coup parfaitement coordonné !<br>
    Si vous mourez dans une partie où il reste deux autres joueurs maléfiques, demandez-leur d’annoncer que leurs rôles ont été échangés.<br>
    Vous paraîtrez alors extrêmement crédible en tant que Barbier, et eux aussi gagneront énormément en crédibilité.<br>
    Par exemple : vous êtes la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> et bluffez le Barbier.<br>
    Vous mourez.<br>
    Le lendemain, le <a href="./vigormortis.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vigormortis</a> et la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a>, qui prétendaient être respectivement le <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a> et le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a>, annoncent que leurs rôles ont été échangés et qu’ils sont désormais le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a> et le <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>.<br>
    Partie.<br>
    Set.<br>
    Match.
  </li>

</ul>
