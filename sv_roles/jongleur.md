##  <span style="color:#4ea3ff;">Résumé</span>  

---

<p style="text-align:left; color:#f5f5f5; font-weight:bold; font-size:20px; margin-top:-10px;">
« Lors de votre premier jour, devinez publiquement jusqu’à 5 rôles de joueurs. Cette nuit, vous apprenez combien étaient corrects.» 
</p> 

<p class="botc-flavour-text dropcap">
LE JONGLEUR prend le risque de convaincre les joueurs de révéler leur rôle lors du premier jour, en espérant en deviner autant que possible, s’ils ne lui ont pas menti.
</p> 

<h2 style="color:#4ea3ff;">Résumé</h2>

<hr class="explication">

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Lors du premier jour, il peut deviner quels joueurs incarnent quels rôles.<br>
    Cette nuit-là, le Jongleur apprend combien de rôles il a correctement devinés... s’il n’est pas tué au préalable.
  </li>

  <li style="margin-bottom:14px;">
    Il doit annoncer ce qu’il devine publiquement afin que tout le monde l’entende.<br>
    Il peut deviner de zéro à cinq rôles.<br>
    Il peut tenter plusieurs fois le même rôle sur des joueurs différents s’il le souhaite, ou plusieurs rôles sur le même joueur.
  </li>

  <li style="margin-bottom:14px;">
    Si le Jongleur était ivre ou empoisonné au moment où il a deviné des rôles, mais qu’il est sobre et sain lorsque sa capacité se déclenche cette nuit-là, le Conteur lui donne la vraie information.
  </li>

</ul>

<h2 style="color:#4ea3ff;">Comment Conter</h2>

---

<p class="botc-flavour-text dropcap">
Instructions au Conteur
</p> 
<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Le premier jour, si le Jongleur annonce qu’il utilise sa capacité, entrez dans le cercle des joueurs avec le Grimoire.
  </li>

  <li style="margin-bottom:14px;">
    Le Jongleur peut faire jusqu’à cinq suppositions.<br>
    Chacune peut concerner n’importe quel rôle et n’importe quel joueur.<br>
    Pour chaque réponse correcte, marquez le Jongleur d’un jeton <strong>CORRECT</strong>.<br>
    (Les joueurs ne doivent pas voir combien de jetons vous placez ainsi.)
  </li>

  <li style="margin-bottom:14px;">
    Cette nuit-là, réveillez le Jongleur.<br>
    Faites signe avec vos doigts (0, 1, 2, etc.) pour lui indiquer le nombre de suppositions <strong>CORRECTES</strong> qu’il a faites.<br>
    Le Jongleur se rendort.<br>
    Retirez les jetons <strong>CORRECT</strong> et le jeton de nuit du Jongleur au moment opportun.
  </li>

</ul>

<div class="botc-note">
Si le Jongleur parle trop vite, demandez-lui de ralentir.
---  
Si un joueur maléfique se fait passer pour le Jongleur, vous pouvez soutenir son bluff en faisant semblant de mettre des jetons dans le Grimoire à mesure qu’il formule ses suppositions.
</div>


<h2 style="color:#4ea3ff;">Exemples</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Le premier jour, le Jongleur devine que Marianna est le <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a>, que Lachlan est le <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a> et qu’Abdallah est le <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a>.<br>
    Cette nuit-là, le Jongleur apprend le chiffre <strong>« 2 »</strong>, ce qui signifie que deux de ces suppositions étaient correctes.
  </li>

  <li style="margin-bottom:14px;">
    Lors de la quatrième nuit, le <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> est transformé en Jongleur.<br>
    Le lendemain, le nouveau Jongleur devine que Ben est la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a>, que Ben est la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> et qu’Amy est la <a href="./pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Guenaude</a>.<br>
    Cette nuit-là, le Jongleur apprend le chiffre <strong>« 1 »</strong>.
  </li>

</ul>

<h2 style="color:#4ea3ff;">Conseils &amp; Astuces</h2>

---

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Essayez de deviner autant de rôles bons que possible !<br>
    Plus vous parvenez à nommer et à confirmer de rôles bons, plus vous aurez de joueurs bons dans le village auxquels vous pourrez faire confiance.<br>
    Cela aide aussi à vous protéger, ainsi que les autres rôles qui recueillent des informations, du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> - vous êtes peut-être une cible prioritaire à vous seule, mais le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> devra choisir très soigneusement si un <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a>, une <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a> et vous-même êtes révélés et actifs.
  </li>

  <li style="margin-bottom:14px;">
    Deviner que quelqu’un est un rôle maléfique est puissant si vous parvenez à le confirmer, mais difficile sans piste.<br>
    Si vous comptez suivre cette voie, essayez de trouver un <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a> et d’obtenir ses informations (il aura forcément un rôle maléfique associé à quelqu’un au moment où vous utiliserez votre capacité !).<br>
    Cela peut aussi être très efficace face à une <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a>.
  </li>

  <li style="margin-bottom:14px;">
    Devinez le nombre maximal de rôles possible - vous obtiendrez une information sur 5 personnes, et le nombre que vous recevrez vous donnera <strong>BEAUCOUP</strong> d’éléments avec lesquels travailler, qu’il confirme ou non les revendications qui vous ont été faites.<br>
    Obtenir le légendaire 5 est extrêmement difficile, mais si vous y parvenez, vous aurez 5 personnes auxquelles vous pourrez faire entièrement confiance - un coup énorme porté à l’équipe maléfique !
  </li>

  <li style="margin-bottom:14px;">
    Devinez un petit nombre de rôles afin d’obtenir une information ciblée sur un groupe précis de joueurs.<br>
    Cela peut être particulièrement efficace pour cibler des joueurs maléfiques, mais vous pouvez aussi l’utiliser pour confirmer la présence d’un <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> en vérifiant une information dont vous savez qu’elle est vraie.
  </li>

  <li style="margin-bottom:14px;">
    Un Jongleur proactif est une cible prioritaire pour le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>
    Envisagez de demander à quelqu’un de revendiquer également votre rôle afin de semer le doute sur l’identité du véritable Jongleur.<br>
    Point bonus si vous trouvez un <a href="./sage.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Sage</a>, puisque si le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> choisit la mauvaise personne, ce sera doublement mauvais pour lui !
  </li>

  <li style="margin-bottom:14px;">
    Convainquez autant de personnes que possible de se révéler, même si vous ne les ciblez finalement pas avec votre capacité.<br>
    L’équipe du Bien prospère grâce à la libre circulation des informations, et votre capacité facilite cela - utilisez-la pour lancer un dialogue dans le village autour des informations.<br>
    Cela permet aussi à l’équipe du Bien de se coordonner tout en ne laissant au <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> aucune cible évidente qu’il devrait absolument choisir - quoi qu’il arrive, quelqu’un sera encore en vie le jour suivant avec de nouvelles informations.
  </li>

  <li style="margin-bottom:14px;">
    Il n’y a aucune pénalité à deviner le mauvais rôle ; en réalité, une information fausse est tout aussi utile qu’une information vraie !<br>
    Si vous n’obtenez pas le nombre attendu, il se peut qu’un joueur maléfique tente de semer la confusion, qu’une <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginale</a> comme la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> essaie de se cacher, ou même que vous ayez été affecté par le <a href="./cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a> !<br>
    Comprendre pourquoi votre nombre était incorrect vous donnera de précieuses informations sur le village.
  </li>

  <li style="margin-bottom:14px;">
    Ceci est moins un conseil pour le Jongleur qu’un conseil pour ses alliés.<br>
    Vous soupçonnez votre Jongleur de ne pas être qui il prétend être ?<br>
    Mentez-lui !<br>
    Lui donner volontairement un faux rôle et voir s’il vous détecte est un excellent moyen de contrer un bluff de Jongleur.<br>
    (Assurez-vous simplement de lui dire la vérité ensuite !)
  </li>

  <li style="margin-bottom:14px;">
    Tout le monde ne voudra pas se révéler à vous.<br>
    Les joueurs maléfiques seront parmi eux - avoir un bluff convaincant dès le premier jour peut être difficile, surtout pour un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.<br>
    Cependant, les <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Marginaux</a> (notamment ceux comme le <a href="./maladroit.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maladroit</a>) et des rôles comme l’<a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a> ou le <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a> seront également réticents, car ils essaieront d’éviter d’attirer l’attention du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.<br>
    Il est légitime de se méfier de toute personne qui ne partage rien, mais ne la condamnez pas automatiquement pour autant.
  </li>

</ul>

<h2 style="color:#4ea3ff;">Bluffer le Jongleur</h2>

---

<p style="color:#f5f5f5; font-size:18px; line-height:1.7;">
  <strong>Lorsque vous bluffez le Jongleur,</strong> il y a quelques éléments à garder en tête:
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin:0; padding:0; list-style-position:inside;">

  <li style="margin-bottom:14px;">
    Ne soyez pas timide.<br>
    Le Jongleur agit publiquement.<br>
    Cela signifie que le Conteur, ainsi que tout le groupe, vous entendront faire vos suppositions.<br>
    Les Jongleurs veulent généralement deviner autant de personnes que possible, et feront de leur mieux pour convaincre le groupe qu’ils sont le Jongleur, et qu’un maximum de personnes devrait révéler son rôle.<br>
    Si vous bluffez en Jongleur, faites parler autant de personnes que possible sur leur identité.
  </li>

  <li style="margin-bottom:14px;">
    Faites-vous paraître bon en ne devinant que des joueurs bons et en confirmant qu’ils disent la vérité.<br>
    Lorsque vous soutenez les revendications de joueurs bons, ils vous feront davantage confiance.<br>
    Par exemple, si vous devinez que la <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a> est la <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a>, que l’<a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> est l’<a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a>, et que le <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> est le <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a>, puis dites au groupe que vos trois suppositions étaient correctes, vous paraîtrez extrêmement utile.
  </li>

  <li style="margin-bottom:14px;">
    Ou, faites paraître des joueurs bons maléfiques en ne devinant que les rôles de joueurs bons, mais en disant au groupe que l’une de vos suppositions était incorrecte.<br>
    Si l’on croit que vous êtes le Jongleur, cela poussera ces joueurs bons à se méfier les uns des autres.<br>
    Par exemple, si vous devinez le <a href="./reveur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Rêveur</a>, l’<a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artiste</a>, la <a href="./couturiere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Couturière</a> et le <a href="./crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur public</a>, mais dites au groupe que vous n’avez obtenu que 3 bonnes réponses sur 4, cela implique que l’un de ces joueurs ment.<br>
    Avec un peu de chance, le groupe se mettra dans tous ses états en essayant de comprendre lequel, et exécutera les quatre joueurs.
  </li>

  <li style="margin-bottom:14px;">
    Soutenez les bluffs de vos alliés maléfiques en devinant leurs rôles.<br>
    Encouragez-les à annoncer quel rôle bon ils revendiquent le premier jour, puis affirmez que vos suppositions étaient correctes.<br>
    Par exemple, devinez que le joueur <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>, qui prétend être la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a>, est bien la <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a>, et que le <a href="./charmeurdeserpent.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Charmeur de serpents</a> est bien le <a href="./charmeurdeserpent.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Charmeur de serpents</a>.<br>
    Lorsque vous dites au groupe que vos deux suppositions étaient correctes, la <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a> paraîtra bonne aux yeux du groupe.
  </li>

  <li style="margin-bottom:14px;">
    Utilisez votre capacité pour affaiblir la crédibilité d’un joueur en particulier, et attirer les soupçons sur lui.<br>
    Vous pouvez ne deviner qu’un seul rôle, puis dire au groupe que votre supposition était incorrecte.<br>
    Vous pouvez aussi deviner son rôle ainsi que celui d’un ou deux joueurs très dignes de confiance, puis dire que l’une de vos suppositions était fausse.<br>
    Cette technique est particulièrement utile si vous ciblez le bon jumeau et parvenez à le faire exécuter, ce qui déclenche la capacité de la <a href="./jumeaumalefique.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Jumelle Maléfique</a> et vous fait gagner la partie.<br>
    De même, attirer beaucoup de soupçons sur un <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> ou un <a href="./horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> peut les faire paraître maléfiques, rendre leurs informations suspectes, et vous donner un peu plus de marge de manœuvre.
  </li>

  <li style="margin-bottom:14px;">
    Méfiez-vous des joueurs rusés, qui peuvent révéler un faux rôle dans l’espoir de vous piéger.<br>
    Certains joueurs bons ont une raison de mentir sur leur identité.<br>
    S’ils le font, et que vous devinez leur véritable rôle, mais dites au groupe que toutes vos suppositions étaient correctes, alors ils sauront que vous mentez.<br>
    Vous pouvez toujours prétendre que ce sont eux qui mentent, ou que l’inexactitude de vos informations est due à un <a href="./nodashii.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">No Dashii</a>, à un <a href="./vortox.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Vortox</a> ou à une <a href="./dulcinee.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Dulcinée</a> morte, mais cet argument sera souvent plus difficile à faire croire.
  </li>

  <li style="margin-bottom:14px;">
    Prétendre être le Jongleur peut révéler des cibles prioritaires que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> voudra tuer.<br>
    De nombreux <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démons</a> voudront éliminer une <a href="./fleuriste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Fleuriste</a>, un <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a> ou un <a href="./oracle.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Oracle</a> aussi vite que possible, ou d’autres rôles puissants selon la configuration actuelle de la partie.<br>
    Pousser les joueurs bons à révéler qui ils sont peut aider le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> à faire un choix judicieux.<br>
    Bien sûr, dans <a href="../sv.html" style="color:#d67bff; font-weight:bold; text-decoration:none;">Sects &amp; Violets</a>, tous les choix sont de bons choix pour le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>, mais certains sont meilleurs que d’autres selon la situation.
  </li>

</ul>
