<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Résumé</span>
</h2>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  <strong>« Chaque nuit* (sauf la première), choisissez un joueur : il meurt.
  Si vous vous tuez de cette façon, un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> vivant devient le nouvel Imp. »</strong>
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> tue un joueur chaque nuit, et peut se copier lui-même… pour un prix terrible.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Chaque nuit (sauf la première), l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> choisit un joueur à tuer.
    Comme la plupart des rôles agissent après le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>,
    ce joueur n’utilisera probablement pas sa capacité cette nuit.
  </li>
  <li>
    L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>, parce qu’il est un <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>, sait quels joueurs sont ses
    <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>,
    et connaît trois rôles bons qui ne sont pas en jeu, qu’il peut bluffer en toute sécurité.
  </li>
  <li>
    Si l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> meurt, la partie se termine et le Bien gagne.
    Cependant, si l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> se tue la nuit, il meurt et un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> vivant devient l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>.
    Ce nouvel <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> n’agit pas cette même nuit, mais il est désormais l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> à tous les autres égards : il tue chaque nuit, et il perd s’il meurt.
  </li>
</ul>

<hr>

<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Comment Conter</span>
</h2>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Chaque nuit (sauf la première), réveillez l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>. L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> pointe un joueur.
    Rendormez l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>. Le joueur choisi meurt : placez le rappel <strong>MORT</strong> de l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> à côté du jeton de rôle de la cible dans le Grimoire
    et placez un linceul.
  </li>
  <li>
    Si l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> s’est tué la nuit, choisissez un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> vivant et remplacez son jeton de rôle
    par un jeton <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> de réserve, changeant son rôle en <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>.
    Réveillez le nouvel <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>, montrez-lui le jeton d’info « VOUS ÊTES », puis montrez-lui le jeton <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>.
    Rendormez le nouvel <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>.
  </li>
  <li>
    À l’aube, annoncez quel joueur est mort pendant la nuit. (Ne dites pas comment il est mort.)
  </li>
  <li>
    Si l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> attaque un joueur mort la nuit, laissez-le faire.
    Quand une capacité dit « choisissez un joueur », cela signifie n’importe quel joueur : vivant ou mort.
    L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> peut vouloir bluffer le
    <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a>,
    et ce genre de choix peut rendre son bluff plus crédible.
  </li>
</ul>

<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Exemples</span>
</h2>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    C’est la première nuit. L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> apprend que Céline et Tanina sont les <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>.
    L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> apprend aussi que le
    <a href="./moine.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Moine</a>,
    le
    <a href="./cuistot.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cuistot</a>
    et le
    <a href="./bibliothecaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Bibliothécaire</a>
    ne sont pas en jeu.
    L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> bluffe le <a href="./cuistot.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cuistot</a>, puis bluffe le
    <a href="./maire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maire</a>
    à mi-partie. Finalement, l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> est exécuté et le Bien gagne.
  </li>
  <li>
    Pendant la nuit, l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> se réveille et choisit un joueur, qui meurt.
    La nuit suivante, l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> se choisit lui-même pour mourir.
    L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> meurt, et l’
    <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a>
    devient l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>.
  </li>
</ul>

<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Astuces &amp; Conseils</span>
</h2>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  Il existe de nombreuses stratégies pour les joueurs maléfiques, en particulier l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>, détaillées plus en profondeur dans la section
  <a href="../strategie.html" style="color:#e0c99d; font-weight:bold; text-decoration:none;">Stratégie</a>.
  En règle générale, en tant que <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>, vous voulez paraître digne de confiance, répandre de fausses informations quand c’est possible,
  pousser vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> à confirmer que vous êtes un joueur du Bien, et les sacrifier quand c’est nécessaire.
  Consultez cette section pour plus d’informations.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Survivez pendant la journée à tout prix. Même dans les parties avec trois <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>, n’assumez pas qu’une
    <a href="./femmeecarlate.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Femme Écarlate</a>
    est en jeu. (Cependant, si vous parlez à vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> et apprenez que c’est le cas, vous pouvez ignorer ce conseil.)
  </li>
  <li>
    Si vous êtes suspect, le suicide nocturne est toujours une option.
    Vous perdez le soutien de la puissance de vote continue de ce <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>,
    mais survivre est plus important. Vous pouvez aussi le faire même sans suspicion :
    les joueurs font souvent plus confiance à ceux qui meurent la nuit.
    Dans tous les cas, si vous mourez la nuit, donner une information fausse au Bien le lendemain,
    comme prétendre être le
    <a href="./gardiendestombes.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien des Tombes</a>,
    peut changer le cours de la partie.
  </li>
  <li>
    Vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> sont des pions à sacrifier. Tuez-les. Tuez-les tous. Vous êtes la seule personne qui compte.
  </li>
  <li>
    Au début de la partie, le Conteur vous donne trois bluffs possibles.
    Vous pouvez bluffer ce que vous voulez, bien sûr, mais ces bluffs sont sûrs.
    Comme l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> peut mourir la nuit et transmettre son rôle de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> à un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, les bluffs passifs comme les bluffs agressifs peuvent être utiles.
    Si vous débutez, demandez de l’aide au Conteur, ou bluffez un rôle passif comme le
    <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a>
    ou le
    <a href="./reclus.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Reclus</a>.
    Si vous êtes plus aventureux, des bluffs plus risqués comme la
    <a href="./voyante.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Voyante</a>
    ou le
    <a href="./croquemort.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Croque-Mort</a>
    peuvent être tentés.
  </li>
  <li>
    Une stratégie très audacieuse, à utiliser parfois avec des joueurs expérimentés, est de revendiquer un rôle que vous n’avez pas reçu en bluff.
    Si vous bluffez un rôle réellement en jeu, le Bien peut supposer que vous êtes juste le
    <a href="./baron.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Baron</a>
    qui n’a pas appris de rôles hors-jeu, et exécuter d’autres joueurs.
    Bien sûr, le groupe peut aussi décider que vous êtes la <a href="./femmeecarlate.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Femme Écarlate</a> et vous exécuter par précaution.
  </li>
  <li>
    Pour vos attaques, tuez tôt les <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> puissants, gênants, et collecteurs d’informations, comme l’
    <a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a>,
    le
    <a href="./croquemort.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Croque-Mort</a>,
    le
    <a href="./moine.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Moine</a>
    ou le
    <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a>.
    Retirer leurs informations (ou leur puissance) tôt vous aide plus tard.
    Parfois, garder volontairement l’un d’eux en vie jusqu’au dernier jour peut servir de double-bluff.
  </li>
  <li>
    Tuez aussi les joueurs les plus crédibles tôt : une
    <a href="./vierge.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Vierge</a>
    que tout le monde connaît ne sera jamais exécutée, ce qui augmente vos chances d’être exécuté plus tard.
    Deux
    <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étrangers</a>
    que tout le monde croit être des <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étrangers</a> devront disparaître, car ils ne seront pas exécutés non plus.
    Au dernier jour, vous voulez au moins un autre joueur, idéalement deux, qui paraissent plus suspects que vous.
  </li>
  <li>
    Envoyez vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> en missions de collecte d’informations. Apprenez qui est qui.
    Cela vous aide à éviter d’attaquer des rôles problématiques comme le
    <a href="./gardiendestombes.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien des Tombes</a>
    ou le
    <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a>,
    et les problèmes qui suivent.
  </li>
  <li>
    Parlez à vos <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a>. Coordonnez-vous : aidez-les à bluffer.
    Décidez que l’un de vous paraîtra très suspect, tandis qu’un autre prendra le rôle de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> et survivra jusqu’à la fin.
    Apprenez ce que sait votre
    <a href="./espion.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Espion</a>.
    Coordonnez-vous avec votre
    <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a>
    pour choisir des cibles différentes la nuit.
    Laissez votre <a href="./baron.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Baron</a> faire n’importe quoi.
    Apprenez si le plan de la <a href="./femmeecarlate.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Femme Écarlate</a> est de vous tuer, ou de vous garder en vie.
  </li>
  <li>
    Il existe de nombreuses raisons pour lesquelles vous pourriez apparaître comme un <a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> maléfique aux bons joueurs.
    Si cela arrive, ne désespérez pas : peut-être pouvez-vous convaincre le groupe que l’<a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a> est ivre,
    ou argumenter que vous êtes le « faux positif » de la <a href="./voyante.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Voyante</a>.
  </li>
  <li>
    Si vous ne voulez pas tuer une nuit, choisissez un joueur mort à la place.
    Cela peut aussi aider votre bluff de <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a> ou de <a href="./moine.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Moine</a> : une nuit sans mort rend ces bluffs plus crédibles.
    Si personne n’est mort après le premier jour, il n’y a pas encore de morts sur lesquels « absorber » une attaque.
    Si vous êtes déterminé à bluffer ces rôles, demandez à votre <a href="./empoisonneur.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Empoisonneur</a> de vous choisir.
  </li>
</ul>

<h2 style="margin-top:10px;">
  <span style="color:#d45b5b; font-weight:bold;">Combattre l’Imp</span>
</h2>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  Dans <strong>Trouble Brewing</strong>, combattre l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> revient à jouer correctement pour l’équipe du Bien :
  pensez à consulter la section
  <a href="../strategie.html" style="color:#e0c99d; font-weight:bold; text-decoration:none;">Stratégie</a>.
  Exécuter le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> fait gagner le Bien.
  Si vous avez une piste sur un <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> possible et une autre sur un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> possible, il est généralement préférable de prioriser l’exécution des suspects <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Savoir qui l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> n’est pas est presque aussi important que savoir qui il est.
    Confirmer d’autres joueurs comme bons permet de construire de la confiance, recouper des informations et bâtir une liste de suspects…
    mais cela réduit aussi le champ des personnes qui ne peuvent pas être le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.
    Au dernier jour, il reste souvent trois joueurs vivants, dont un <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> :
    si vous n’êtes pas certain du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> mais que vous pouvez affirmer qu’une de ces personnes est bonne,
    vous avez alors une chance sur deux d’exécuter la bonne cible.
  </li>
  <li>
    Des rôles comme le
    <a href="./gardiend.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien</a>
    ou le
    <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a>
    sont particulièrement utiles pour innocenter des joueurs.
    Trouver un maléfique est excitant, mais innocenter un bon joueur peut être tout aussi puissant.
  </li>
  <li>
    Si quelqu’un meurt de manière inattendue à un moment étrange, ou après être devenu très suspect,
    vous venez peut-être de voir l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> se tuer et transmettre le rôle de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> à un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.
    C’est une information énorme : 
    savoir que cette personne est maléfique vous permet d’analyser tout ce qu’elle a fait pour identifier l’autre partie de l’équipe du Mal.
    C’est là que l’information du
    <a href="./cuistot.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Cuistot</a>,
    de l’
    <a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a>
    et de l’
    <a href="./enqueteur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Enquêteur</a>
    devient particulièrement précieuse.
    Même s’ils ne sont pas en jeu, vous avez d’autres angles :
    avec qui cette personne parlait-elle, qui a-t-elle « confirmé », qui a-t-elle protégé, quelles informations a-t-elle cherché à rendre crédibles ?
  </li>
  <li>
    Attention à la
    <a href="./femmeecarlate.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Femme Écarlate</a>.
    Tant qu’il y a cinq joueurs ou plus en vie, l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> peut être exécuté et l’équipe du Mal peut continuer.
    Si vous pensez savoir qui est l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a>, envisagez de retarder l’exécution jusqu’à ce qu’il reste moins de cinq joueurs,
    afin que sa capacité ne puisse pas s’activer et que le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> soit stoppé net.
  </li>
  <li>
    L’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> peut être très efficace pour éliminer les rôles menaçants.
    Pour protéger vos rôles à information continue (comme le 
    <a href="./croquemort.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Croque-Mort</a>,) 
    ou à capacité puissante (comme la 
    <a href="./vierge.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Vierge</a>,),
    essayez d’inciter l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> à attaquer de mauvaises cibles.
    Par exemple, un 
    <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a> ou un 
    <a href="./maire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Maire</a> 
    peut bluffer une cible intéressante, laissant sa capacité encaisser l’attaque.
    À l’inverse, le
    <a href="./saint.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Saint</a>,
    le
    <a href="./reclus.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Reclus</a>
    ou la
    <a href="./lavandiere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Lavandière</a>
    peuvent chercher à attirer l’attention du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> : ils mourront, mais c’est parfois mieux que perdre votre <a href="./voyante.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Voyante</a>.
  </li>
  <li>
    Si vous jouez à six joueurs ou moins, les règles du <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> changent légèrement :
    il ne commence pas avec des bluffs, et il ne sait pas qui est son <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>.
    Une stratégie amusante est de bluffer être le <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> auprès d’un autre joueur,
    et d’encourager le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> à se confier à vous. S’il admet être le <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>, vous pouvez le révéler au village pour une victoire décisive.
  </li>
  <li>
    Contrairement à d’autres <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démons</a>, la capacité de l’<a href="./imp.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Imp</a> à transmettre le rôle de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> aux <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbires</a> lui permet des bluffs complexes,
    souvent impliquant plusieurs joueurs. Surveillez les groupes de joueurs qui se « confirment » mutuellement.
    Par exemple :
    <ul style="margin-top:10px;">
      <li>
        Bluffer
        <a href="./lavandiere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Lavandière</a>
        ou
        <a href="./bibliothecaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Bibliothécaire</a>
        et confirmer que son <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> est un <a href="../villageois.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Villageois</a> ou un <a href="../etrangers.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Étranger</a> (très fort si le <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> prétend être le <a href="./saint.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Saint</a>).
      </li>
      <li>
        Bluffer l’
        <a href="./empathique.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Empathique</a>
        en affirmant avoir deux voisins bons, puis mourir « trop opportunément » et transmettre au <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> voisin.
      </li>
      <li>
        Choisir de mourir puis bluffer le
        <a href="./gardien.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Gardien</a>
        afin de confirmer le bluff d’un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> devenu <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.
      </li>
      <li>
        Bluffer le
        <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a>,
        « tirer » sur son <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>, puis mourir. (Variante : pousser un vrai <a href="./mercenaire.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mercenaire</a> bon à tirer sur le <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a>,
        puis transmettre au <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> après qu’il a été confirmé non-<a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a>.)
      </li>
      <li>
        Choisir de ne tuer personne une nuit pour permettre à un <a href="../sbires.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sbire</a> de bluffer 
        <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a> ou 
        <a href="./moine.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Moine</a>.
        Les joueurs font très souvent confiance à un 
        <a href="./soldat.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Soldat</a> 
        s’il n’y a pas eu de mort, ce qui en fait un excellent candidat pour reprendre le rôle de <a href="../demons.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Démon</a> plus tard.
      </li>
    </ul>
  </li>
</ul>
