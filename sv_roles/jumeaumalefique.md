<h2 style="color:#d45b5b; font-weight:bold;">Résumé</h2>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  « Vous et un joueur d’alignement opposé vous connaissez.<br>
  Si le joueur bon est exécuté, les Maléfiques gagnent.<br>
  Le Bien ne peut pas gagner si vous êtes tous deux en vie. »
</p>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  Le <strong>Jumeau Maléfique</strong> est un sbire qui crée un lien miroir avec un joueur bon appelé le <strong>Jumeau Bon</strong>.<br>
  Chacun connaît le rôle de l’autre.<br>
  Toute la tension du jeu repose sur la confusion : lequel des deux dit la vérité ?<br>
  L'Équipe des <strong>gentils</strong> ne savent pas quel jumeau est bon et quel jumeau est maléfique.
</p>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Si le <strong>Jumeau Bon</strong> est exécuté → 💀 le Mal gagne immédiatement.</li>
  <li>Si le <strong>Jumeau Maléfique</strong> est exécuté → la partie continue.</li>
  <li>Tant que les deux sont vivants → le Bien ne peut pas gagner, même si le Démon meurt.</li>
</ul>

<hr>

<h2 style="color:#d45b5b; font-weight:bold;">Comment Conter</h2>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    <strong>Avant la première nuit :</strong><br>
    Choisissez un joueur bon et placez sur sa fiche le jeton de rappel <em>Jumeau</em>.
  </li>

  <li>
    <strong>Première nuit :</strong><br>
    Réveillez les deux Jumeaux.<br>
    Laissez-les se reconnaître.<br>
    Montrez au Jumeau Bon le jeton de rappel <em>Jumeau Maléfique</em>.<br>
    Montrez au Jumeau Maléfique le jeton du rôle du Jumeau Bon.
  </li>

  <li>
    <strong>Pendant la partie :</strong><br>
    Si le Jumeau Bon est exécuté → les Maléfiques gagnent.<br>
    Si le Jumeau Maléfique est exécuté → la partie continue.<br>
    Tant que les deux sont en vie, le camp du Bien ne peut pas gagner.
  </li>
</ul>

<p style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:20px; margin-right:20px;">
  Si lors de la dernière nuit, une
  <a href="pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Pit-Hag</a>
  crée un nouveau Jumeau Maléfique,<br>
  choisissez un joueur mort ou le Démon comme second jumeau pour ne pas bloquer la partie,<br>
  afin que la bonne équipe puisse toujours gagner.<br>
  Évitez de choisir un Voyageur comme Jumeau.
</p>

<h2 style="color:#d45b5b; font-weight:bold;">Exemples</h2>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>
    Les deux Jumeaux prétendent être l’
    <a href="horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a>.<br>
    Le Jumeau Maléfique est exécuté : la partie continue.
  </li>

  <li>
    La
    <a href="pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Pit-Hag</a>
    transforme le
    <a href="./savant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Savant</a>
    (le Jumeau Bon) en
    <a href="./mutant.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Mutant</a>.<br>
    Les deux prétendent être le Mutant. Le Conteur exécute le Jumeau Bon : <strong>les Maléfiques gagnent.</strong>
  </li>

  <li>
    Les deux Jumeaux se disent
    <a href="./artiste.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Artistes</a>.<br>
    Le village exécute le Démon, mais la nuit suivante il n’y a pas de morts : le Jumeau Maléfique vit encore.
  </li>

  <li>
    La
    <a href="pithag.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Pit-Hag</a>
    transforme un joueur bon en Jumeau Maléfique, mais il reste bon.<br>
    Le village l’exécute : <strong>le Mal gagne.</strong>
  </li>
</ul>

<h2 style="color:#d45b5b; font-weight:bold;">Astuces &amp; Stratégies</h2>

<h3 style="color:#d45b5b; font-weight:bold;">Pour le Jumeau Maléfique</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li><strong>Retournez la situation.</strong><br>Dites que l’autre est le Jumeau Maléfique et répétez-le sans relâche.</li>

  <li><strong>Imitez son rôle.</strong><br>Vous connaissez le rôle du Jumeau Bon, bluffez le même pour maintenir le doute.</li>

  <li><strong>Jouez la peur et la passion.</strong><br>Le Jumeau Bon se bat pour ne pas être exécuté ; imitez-le pour paraître sincère.</li>

  <li><strong>Manipulez le risque.</strong><br>“Si vous me tuez et que je suis le bon, vous faites gagner les Maléfiques !”<br>Cette phrase bloque souvent les votes.</li>

  <li>
    <strong>Travaillez avec les autres Sbires.</strong><br>
    Le
    <a href="cerenovus.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Cerenovus</a>
    peut rendre le Jumeau Bon fou d'être un autre rôle,<br>
    et la
    <a href="./sorciere.html" style="color:#d45b5b; font-weight:bold; text-decoration:none;">Sorcière</a>
    peut le maudire pour le condamner lors d'une nomination.
  </li>

  <li><strong>Le Démon peut cesser de tuer.</strong><br>Si les morts s’arrêtent, les bons croiront que le Démon est mort,<br>ce qui renforce votre bluff.</li>
</ul>

<h3>Pour le camp du Bien</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li><strong>Ne vous précipitez pas.</strong><br>Attendez plusieurs jours d’informations avant d’exécuter l’un des deux Jumeaux.</li>
  <li><strong>Comparez les récits.</strong><br>Le vrai Jumeau Bon sera cohérent, tandis que le Maléfique improvisera.</li>
  <li><strong>Observez les comportements.</strong><br>Le Jumeau Maléfique parle souvent trop ou répète ses arguments.</li>
</ul>

<h3 style="color:#d45b5b; font-weight:bold;">Rôles utiles contre le Jumeau Maléfique</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li><a href="crieur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Crieur</a> – détecte si un Jumeau a fait une nomination.</li>
  <li><a href="jongleur.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Jongleur</a> – peut deviner qui est le Jumeau Maléfique.</li>
  <li><a href="couturiere.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Couturière</a> – compare les alignements.</li>
  <li><a href="horloger.html" style="color:#4ea3ff; font-weight:bold; text-decoration:none;">Horloger</a> – peut aider à identifier le Démon et donc le Jumeau.</li>
</ul>

<h3 style="color:#d45b5b; font-weight:bold;">Pour le jumeau maléfique</h3>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li><strong>Niez tout.</strong><br>Prétendez qu’il n’y a pas de Jumeau et accusez votre double de mentir.</li>
  <li><strong>Double bluff.</strong><br>Jouez le rôle du “Jumeau Bon” sincère pour tromper le village.</li>
  <li><strong>Fausse paire maléfique.</strong><br>Deux sbires peuvent se désigner mutuellement comme Jumeaux pour semer la confusion.</li>
</ul>

<hr>

<h2 style="color:#d45b5b; font-weight:bold;">Combattre le Jumeau Maléfique</h2>

<ul style="color:#f5f5f5; font-size:18px; line-height:1.7; margin-left:40px;">
  <li>Si <strong>un seul joueur accuse un autre</strong> d’être le Jumeau Maléfique,<br>croyez <strong>l’accusateur</strong> : il est souvent le vrai Jumeau Bon.</li>
  <li>Si <strong>les morts cessent soudainement</strong>, le Démon a probablement été tué,<br>mais la partie continue : le Jumeau Maléfique est toujours vivant.</li>
  <li>Pour gagner, le Bien doit exécuter <strong>le Démon ET le Jumeau Maléfique</strong>.</li>
</ul>
